因为terser 只会压缩 JS 文件，完全不管 CSS的压缩；rollup-plugin-css-only 本职仅提取、合并样式，天生不带压缩功能。
故需新增 css 压缩依赖（推荐），依靠 postcss + cssnano 实现 CSS 压缩，兼容 IE9，不会打乱你现有的目录、引入规则

npm uninstall rollup-plugin-css-only -D

# 安装依赖（最新版）
npm install rollup-plugin-postcss cssnano autoprefixer --save-dev
# 安装依赖（指定版本 PostCSS 8 cssnano 5npm）
npm i rollup-plugin-postcss postcss@8 cssnano@5.0.17 autoprefixer --save-dev



【说明】
关键版本边界区分
PostCSS 9：强制要求 Node ≥18，老旧环境会直接报错
PostCSS 8：兼容 Node 10.13 / 12 /14 /16 /18，最稳妥、适配面最广
cssnano v5：最低 Node10.13，和 PostCSS8 完美搭档


依赖作用拆解：
rollup：打包核心工具
rollup-plugin-terser：JS 代码压缩混淆（ES5 友好，不会破坏 IE 语法）
rollup-plugin-css-only：单独抽离 CSS 文件，不和 JS 打包混杂
第四步：编写 rollup.config.js 打包配置文件（根目录新建）
javascript
运行
// rollup.config.js
import { terser } from 'rollup-plugin-terser';
import css from 'rollup-plugin-css-only';

// 打包配置数组：同时输出未压缩版、压缩版
export default [
    // 1. 未压缩开发版
    {
        input: 'src/components/dialog/index.js', // 组件入口文件
        output: {
            file: 'dist/dialog.js', // 输出路径
            format: 'umd', // 通用模块格式
            name: 'MelUi', // 全局挂载变量名 window.MelUi
            exports: 'default'
        },
        plugins: [
            css({
                output: 'dist/dialog.css' // 提取css输出位置
            })
        ]
    },
    // 2. 压缩生产版
    {
        input: 'src/components/dialog/index.js',
        output: {
            file: 'dist/dialog.min.js',
            format: 'umd',
            name: 'MelUi',
            exports: 'default'
        },
        plugins: [
            css({
                output: 'dist/dialog.min.css'
            }),
            terser({
                ecma: 5, // 强制输出ES5语法，保障IE兼容
                mangle: true,
                compress: true
            })
        ]
    }
];
