
对话框dialog需求


1、参数 content 改为 message
2、去掉title、message、button之间的线
3、默认文字水平方向：title、message居左、button居中(按钮居右)
4、当参数title为空时，body高度要大概在100左右，才不会显示很扁
5、showClose默认为true，且hover时为主题色
6、新增参数: 
（1）是否水平居中布局：比如horizontal，水平居中时 header,body,footer均水平居中
（2）message是否居中布局：优先级高于【水平居中布局】，默认false
（3）点击遮罩是否关闭弹窗：默认true
（4）可自定义对话框内容，类似elementUI的dangerouslyUseHTMLString: true
（5）新的弹窗类型：Message消息提示。类似于elementUI的【Message 消息提示】，有几种不同的状态（主题）成功、警告、消息、错误。可自定义消息出现的方向。
（6）新的弹窗类型：轻提示，类似天猫、京东等加入购物车等只是轻提示（如居中提示），过一会儿就消失了。可自定义方向：居中、顶部、底部等，自定义不同的状态。
（7））禁用按钮：即可一键禁用按钮，点击按钮不发生任何反应

7、设备平台的不同：一般pc端和移动端，信息的展示方式可能有所不同，比如移动端时按钮就不显示为按钮，成功主题时pc按钮是绿色背景，移动端时就得文字绿色。比如：移动端时右上角的按钮多数场景下是不显示的。
这个可以考虑增加一个参数：device: "phone"来一键进行设置，如果不使用这个参数，则用户得自己根据参数一个个个设置。

8、prompt模式太简单，要扩展几个参数：
eg. 
prompt {
    type 输入框类型，默认input。值：input 单行, textarea 多行。
    placeholder 输入框默认提示信息
    defaultValue 输入框默认值
}

（1）标准引入方式

（3）极简快捷弹窗，用dialog,alert分别演示，只要传 message 参数即可
（4）Message消息提示
（5）Alert提示信息弹窗：用alert演示不同主题的弹窗 + 有标题弹窗 + 无标题弹窗、自定义按钮名称的弹窗
（6）Confirm确认对话框：用confirm分别演示几种情况：有标题、无标题、自定义按钮名称、按钮垂直排列、按钮按钮通栏铺满

onClick里面调用 melui.alert 点确认时，页面滚动条没了，因为html,body的overflow属性存在。

melui.confirm({
    title: "删除确认",
    message: "数据删除后无法恢复，确认继续吗？",
    theme: "danger",
    onClick: function(ret) {
        if(ret === 2) {
            melui.alert({ message: "确认删除" });
        }
    }
});

4、关于 height 参数问题
height设置后，对话框高度固定了，但是如果height值比较大，会导致对话框很高，但是按钮显示半空中，而不是对话框底部，这样很难看。
理想的状态是：height无论设置多大，按钮都要居于底部一定距离，中间的部分高度自动展开，这样 confirm 设置textbox时，textbox的内容高度就能占满中间部分
考虑：加一参数，用于控制按钮是否一直在底部，默认true，如果设置了height或fullscreen，按不想居底部，则用户把此此参数设置为false即可，按就会自动在内容下面位置。
