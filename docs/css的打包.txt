


# MellowUi 完整汇总

环境：Win7 + Node13
业务约束：**不修改组件 index.js，不在 JS 里写 import css**；执行一次 `npm run build`，输出 js /min.js/css /min.css



## 一、根本原因：为什么 rollup 不能直接输出独立 CSS

1. Rollup 是 JS 打包器，沿着 JS 的 `import` 依赖图收集文件。
2. `rollup‑plugin‑postcss` **只能处理被 JS 导入的 css**，不会自动扫描磁盘上孤立的 css 源文件。
3. ❌禁止：把 css 文件直接写为 rollup `input`，会报错 `Could not resolve entry module`，rollup 不支持 css 作为入口。
4. 两条路线：
   - 路线 A：组件 js 写`import './xxx.css'` → css 由 rollup 输出；你不采用。
   - 路线 B：rollup 只管 JS 打包；CSS 交给外部 node 脚本编译，scripts 串行执行（本项目采用）。

> 
> ⚠️你的 `rollup.config.js` **保持你原始文件完全不动，不要做任何改动**。

## 二、三套方案总览

表格

| 方案 | 所需安装包 | 优点 | 缺点 | 本项目建议 |
| --- | --- | --- | --- | --- |
| 方案 A：脚本 + fs‑extra（已装） | `fs‑extra@9.1.0` | 代码简洁，`ensureDir`一键创建多级目录 | 多一个第三方依赖 | ✅首选 |
| 方案 B：原生 Node fs，不使用 fs‑extra | 无需新增安装包 | 零第三方依赖 | 需要手写递归建目录函数 | ✅兜底备用 |
| 方案 C：postcss‑cli | `postcss‑cli@8.0.0` | 不用写 js 脚本 | Win7 Node13 下：新版本 ESM 报错；旧版不支持 cmd 通配符，必须手写全部 css 路径 | ❌不推荐 |

> 
> 提示：安装 fs‑extra 出现 `fsevents` 警告，是 macOS 专属可选包，Windows 直接忽略，不是错误。

# 方案 A：使用 fs‑extra（首选）

### 1. 安装步骤

```
# Win7必须指定版本9，高版本要求node14+
npm install fs-extra@9 --save-dev
```

### 2. 根目录新建 `build‑css.js`

```
const fs = require('fs-extra');
const postcss = require('postcss');
const autoprefixer = require('autoprefixer');
const cssnano = require('cssnano');

// 新增组件在这里添加
const components = [
  { name: 'dialog', src: 'src/components/dialog/dialog.css', outDir: 'dist/dialog' },
  { name: 'datePicker', src: 'src/components/datePicker/datePicker.css', outDir: 'dist/datePicker' },
  { name: 'drawer', src: 'src/components/drawer/drawer.css', outDir: 'dist/drawer' }
];

async function buildAllCss() {
  for (const item of components) {
    await fs.ensureDir(item.outDir);
    const sourceCss = await fs.readFile(item.src, 'utf8');

    // 开发版css：仅autoprefixer加浏览器前缀
    const devResult = await postcss([
      autoprefixer({ overrideBrowserslist: ['IE 9', 'IE 10', 'IE 11', 'last 2 versions'] })
    ]).process(sourceCss, { from: item.src });
    await fs.writeFile(`${item.outDir}/${item.name}.css`, devResult.css);

    // 压缩min版css：前缀 + cssnano压缩
    const minResult = await postcss([
      autoprefixer({ overrideBrowserslist: ['IE 9', 'IE 10', 'IE 11', 'last 2 versions'] }),
      cssnano({ preset: ['default', { discardComments: { removeAll: true }, normalizeWhitespace: true }] })
    ]).process(sourceCss, { from: item.src });
    await fs.writeFile(`${item.outDir}/${item.name}.min.css`, minResult.css);

    console.log(`✅ ${item.name} css 编译完成`);
  }
}

buildAllCss().catch(err => {
  console.error('❌ CSS编译异常：', err);
  process.exit(1);
});
```

### 3. 修改 package.json scripts

```
"scripts": {
  "test": "echo \"Error: no test specified\" && exit 1",
  "clean": "if exist dist rmdir /s /q dist",
  "build:js": "rollup -c",
  "build:css": "node build-css.js",
  "build": "npm run clean && npm run build:js && npm run build:css"
}
```

### 4. 执行构建

```
npm run build
```

# 方案 B：原生 Node fs（不使用 fs‑extra，兜底方案，无需任何安装）

> 
> 适用：fs‑extra 出现兼容异常，直接切换，**不需要 npm 安装任何包**，使用 node 内置 `fs / path`。

### 1. 安装：无，不需要执行 npm 安装命令

### 2. 根目录新建 `build‑css.js`

```
const fs = require('fs');
const path = require('path');
const postcss = require('postcss');
const autoprefixer = require('autoprefixer');
const cssnano = require('cssnano');

// 原生递归创建文件夹
function ensureDir(dir) {
  return new Promise((resolve, reject) => {
    fs.mkdir(dir, { recursive: true }, err => {
      if (err) return reject(err);
      resolve();
    });
  });
}

const components = [
  { name: 'dialog', src: 'src/components/dialog/dialog.css', outDir: 'dist/dialog' },
  { name: 'datePicker', src: 'src/components/datePicker/datePicker.css', outDir: 'dist/datePicker' },
  { name: 'drawer', src: 'src/components/drawer/drawer.css', outDir: 'dist/drawer' }
];

async function buildAllCss() {
  for (const item of components) {
    await ensureDir(item.outDir);
    const sourceCss = await fs.promises.readFile(item.src, 'utf8');

    const devResult = await postcss([
      autoprefixer({ overrideBrowserslist: ['IE 9', 'IE 10', 'IE 11', 'last 2 versions'] })
    ]).process(sourceCss, { from: item.src });
    await fs.promises.writeFile(path.join(item.outDir, `${item.name}.css`), devResult.css);

    const minResult = await postcss([
      autoprefixer({ overrideBrowserslist: ['IE 9', 'IE 10', 'IE 11', 'last 2 versions'] }),
      cssnano({ preset: ['default', { discardComments: { removeAll: true }, normalizeWhitespace: true }] })
    ]).process(sourceCss, { from: item.src });
    await fs.promises.writeFile(path.join(item.outDir, `${item.name}.min.css`), minResult.css);

    console.log(`✅ ${item.name} css 编译完成`);
  }
}

buildAllCss().catch(err => {
  console.error('❌ CSS编译异常：', err);
  process.exit(1);
});
```

### 3.package.json scripts 和方案 A 完全一样，无需改动

```
"scripts": {
  "test": "echo \"Error: no test specified\" && exit 1",
  "clean": "if exist dist rmdir /s /q dist",
  "build:js": "rollup -c",
  "build:css": "node build-css.js",
  "build": "npm run clean && npm run build:js && npm run build:css"
}
```

### 4. 执行构建

```
npm run build
```

# 方案 C：postcss‑cli（仅记录，本项目 Win7 环境不推荐）

> 
> 仅做文档记录，不建议实际使用

### 1. 安装（Win7 必须锁版本）

```
npm install postcss-cli@8.0.0 --save-dev
```

> 
> 高于 8 版本为 ESM 模块，Node13 Win7 会报语法错误。

### 2. 缺陷

Windows cmd ** 不支持 glob 通配符 `**/*.css`，必须把每一个 css 完整路径写死在 scripts；新增组件就要改 scripts，维护麻烦。

---

## 公共说明（两套脚本通用）

1. `rollup.config.js` 全程保持你原来的代码，**不要改，不要把 css 作为 input 入口**。
2. dist 产物：每个组件目录生成 `.js` / `.min.js` / `.css` / `.min.css`；根目录输出 `melui.js`、`melui.min.js`。
3. 新增组件：只修改 `build‑css.js` 中 `components` 数组，增加一行对象配置。
4. 报错排查：
   - ENOENT：css 源文件不存在、路径 / 大小写写错；
   - 看不到 `✅ xxx css编译完成`：css 脚本执行失败，看控制台打印的错误详情；
   - rollup 报`Could not resolve entry module`：rollup 配置被修改，恢复原始配置。

## 执行流程（npm run build）

1. clean：删除整个 dist 文件夹
2. build:js：rollup 读取 rollup.config.js，打包全部 js
3. build:css：node 运行 build‑css.js 脚本，编译输出 css、min.css
