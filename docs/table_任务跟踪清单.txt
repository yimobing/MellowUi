MelUi Table 未实现功能清单（按改动难度分档）
=====================================

门槛说明：
P1 = 局部小改，1 个文件内加判断/加分支，半天内
P2 = 需动数据结构或新增独立插件，1~2 天
P3 = 需要重构渲染网格或与多模块联动，3 天以上

────────────────────────────
P1｜简单
────────────────────────────
1. 列配置 sortable 开关 (ok)
   Sort 插件加列级判断：sortable:false 的列点击表头不排序。
   改动点：sort.js 绑定处 + 表头渲染时区分可排/不可排样式。

2. 列配置 visible 开关（列显隐） (ok)
   渲染前按 visible 过滤列；已导出的 includeHiddenColumns 可复用同一份"隐藏列"概念。
   注意：过滤后要同步重算列宽、fixedLeftColumns 的列数、合并表头 children。
   改动点：renderer.js 列集合构建 + index.css 无改动。

3. 校验钩子 validator (ok)
   列配置增加 validator(value, rowData, rowIndex)，返回错误提示字符串；
   接入现有 validate() 校验链路。底层 validate() / validateUnique() 已存在。
   改动点：table.js 校验循环里加一段。

4. Export 插件原生 CSV 导出 (ok)
   现在只有 HTML 伪装的 .xls；加一个 csv 分支，纯字符串拼装 + BOM 处理中文。
   改动点：export.js 一处方法分支。

────────────────────────────
P2｜中等
────────────────────────────
5. 表尾合计固定（纵向冻结表尾）(ok)
   Summary 的合计行目前只是表身末尾一行，跟着滚动走；
   要做成滚动时始终贴底，需要把合计行从 tbody 拆出，独立成固定层。
   改动点：summary.js 渲染结构 + index.css 定位 + renderer 滚动同步。

6. 右侧固定列 fixedRightColumns（操作列固定）
   现有左侧固定列逻辑可镜像复用，但要处理左右同时冻结时的中间滚动区宽度、
   以及列顺序（右侧固定列必须排在最后）。改动点：renderer.js 列分区 + layout + css。

7. Summary 分组小计
   按指定字段分组聚合，渲染多行小计；需处理与分页、排序、展开行的交互。

8. 多列排序
   dataStore 的 sortField 由单值改数组，表头显示排序优先级序号；
   需兼容 sortCurrentPageOnly 的当前页切片排序。

9. 列头部筛选插件
   表头挂筛选控件，联动数据源过滤；需与分页总数、导出、合计联动。
   新增独立插件文件。


────────────────────────────
P3｜较难（要重构渲染网格或跨多模块）
────────────────────────────
10. 单元格合并（表身合并行或列）
    相邻行/列同值自动 rowspan / colspan；难点是与行高、固定列、展开行、
    单元格输入控件的坐标映射全部要改，等于表身网格重写。

11. 列宽拖拽调整
    table-layout:fixed 下的拖拽手柄 + 实时列宽回写；需同步合并表头、
    固定列、合计行、右侧固定列（若已有）。与 12 高度重叠。

12. 打印插件
    分页打印、每页重复表头、列宽与固定列在打印介质下的重排、IE9 打印兼容。

13. 行拖拽排序
    拖拽行交换位置，需与 rowId、状态列、已选行、分页区间全部对齐。

14. Excel 复制粘贴
    从剪贴板解析行列数据、类型转换、必填/唯一校验、粘贴到当前页草稿行。

15. 树形表格与懒加载
    子行展开为真实数据行（不是详情面板），需要行层级、缩进、父子选中联动。

16. 虚拟滚动
    只渲染可视区行；与固定列、合并表头、单元格输入控件（输入中不能回收）冲突最大，
    需要一整套行复用机制。

17. Layout 布局增强插件补完
    文件已有但功能未完成：双侧固定列、列宽拖拽、弹性混合列宽、resize 重排。
    启用后会接管 renderer.js 现有内置布局计算，属重构级。
    （与 6 / 11 是同一块地基，建议合并成一个专项做）
