    MelUi Util 工具库

    版本 v1.0.0  ·  兼容 IE9~11  ·  纯 ES5  ·  基础层 + 扩展模块
    本页按当前 util 产物更新。浏览器打开后可按 F12 打开控制台，直接输入 melui.util.date.getNowTime() 等示例测试。
    统一调用入口
    melui.util.模块.函数()
    基础层例外：melui.util.isArray()、melui.util.mergeObj()。扩展模块：melui.util.date.getNowTime()、melui.util.dom.getHtml()。

    一、库整体说明基础层 + 扩展模块，按命名空间分组

    Util 是 MelUi 的独立工具层。基础层随主包发布，扩展模块单独打包成 melui-util.js，可以脱离 UI 组件单独使用。

    代码分三层，看文件位置就能分辨职责：

    
src/util/base/      共享基础层，主包与 util 扩展包都包含
src/util/*.js       扩展模块，随 melui-util.js 发布
src/util/util.js    util 扩展包入口，负责分组挂载到 melui.util

    调用形态：基础层扁平挂载，写 melui.util.isArray()；扩展模块按模块名分组，写 melui.util.date.getNowTime()、melui.util.dom.getHtml()。

    函数边界：date / format / string / validate / array / random / biz 不创建 DOM；dom 与 widget 会直接读写 DOM。所有函数均为纯 ES5，不依赖 Object.assign、Object.keys 等在 IE9 缺失的能力。

    二、使用方式主包、扩展包、两者共存与 Node 引用

    1、只引主包

    引入全量 melui.js，只能使用主包内置的基础层函数；melui.util.date 等扩展模块还不存在。

    
<link rel="stylesheet" href="./dist/melui.min.css">
<script src="./dist/melui.min.js"></script>
<script>
    melui.util.mergeObj({ a: 1 }, { b: 2 });
    melui.util.isArray([]);
</script>

    2、只引 util 扩展包

    只想要工具、不需要 UI 组件时，可以只引 melui-util.js。此时工具函数全部可用，但没有 showLoading、Dialog 等组件 API。

    
<script src="./dist/melui-util.min.js"></script>
<script>
    melui.util.isArray([]);                 // true
    melui.util.date.getNowTime();           // 当前时间
    melui.util.dom.getHtml(document.body);  // body 的 innerHTML
</script>

    3、主包与扩展包同时引入

    两者都在时，工具会合并到同一个 melui.util 上，先加载哪个都不影响调用。

    
<link rel="stylesheet" href="./dist/melui.min.css">
<script src="./dist/melui.min.js"></script>
<script src="./dist/melui-util.min.js"></script>
<script>
    melui.util.mergeObj({ a: 1 }, { b: 2 }); // 主包 base
    melui.util.date.getNowTime();            // 扩展模块
</script>

    4、Node / 构建工具引用

    melui.js 与 melui-util.js 都是 UMD 产物。浏览器请用 script 引入；Node 或支持 UMD 的构建工具可以按下面方式引用，不要把 UMD 文件直接当浏览器原生 ESM 模块 import。

    
var MelUi = require('./dist/melui.js');
var util = require('./dist/melui-util.js');

util.mergeObj({ a: 1 }, { b: 2 });
util.date.getNowTime();
MelUi.util.isArray([]);

    合并规则：扩展包按 key 合并进已有的 melui.util，同名的以后加载的为准，先加载的其它工具不会被清空。

    加载顺序：如果扩展包先于主包加载，在主包执行完成之前，melui.showLoading 等 UI API 还不存在，此时只能使用 melui.util。

    按需引入：melui-util.js 已包含基础层与扩展模块；如果只需要基础层，可以直接只引主包，不必额外加载扩展包。

    三、主包内置工具引入 melui.js 即可使用基础函数

    分两组：类型判断与对象工具。调用统一写作 melui.util.函数名(...)。

    3.1 类型判断

    isPlainObject(val)

    功能：判断是否为普通对象。数组、null、Date、RegExp、DOM 节点、window 都返回 false。 兼容：IE9+
    签名与参数
    
melui.util.isPlainObject(
    val   // {*} 任意值
);
// return {Boolean} 是普通对象返回 true
    示例
    
melui.util.isPlainObject({ a: 1 });        // true
melui.util.isPlainObject([]);              // false
melui.util.isPlainObject(null);            // false
melui.util.isPlainObject(new Date());      // false
melui.util.isPlainObject(document.body);   // false

    isArray(val)

    功能：判断是否为数组。用 Object.prototype.toString 判定，跨 iframe 传进来的数组同样能识别。 兼容：IE9+
    签名与参数
    
melui.util.isArray(
    val   // {*} 任意值
);
// return {Boolean} 是数组返回 true
    示例
    
melui.util.isArray([]);            // true
melui.util.isArray({ length: 0 }); // false  类数组对象不算数组
melui.util.isArray('abc');         // false

    isFunction(val)

    功能：判断是否为函数，等价于 typeof val === 'function'。 兼容：IE9+
    签名与参数
    
melui.util.isFunction(
    val   // {*} 任意值
);
// return {Boolean} 是函数返回 true
    示例
    
melui.util.isFunction(function () {});   // true
melui.util.isFunction(Function);         // true
melui.util.isFunction({});               // false

    isNumber(val)

    功能：判断是否为数字类型且不是 NaN。字符串形式的数字不算；Infinity 属于数字类型，返回 true。 兼容：IE9+
    签名与参数
    
melui.util.isNumber(
    val   // {*} 任意值
);
// return {Boolean} 是数字返回 true
    示例
    
melui.util.isNumber(12);        // true
melui.util.isNumber(0);         // true
melui.util.isNumber(NaN);       // false   NaN 不算数字
melui.util.isNumber(Infinity);  // true    Infinity 仍是 number 类型
melui.util.isNumber('12');      // false   字符串不算数字

    isString(val)

    功能：判断是否为字符串，等价于 typeof val === 'string'；包装对象 new String() 不算。 兼容：IE9+
    签名与参数
    
melui.util.isString(
    val   // {*} 任意值
);
// return {Boolean} 是字符串返回 true
    示例
    
melui.util.isString('');                // true
melui.util.isString('abc');             // true
melui.util.isString(new String('abc')); // false  包装对象不算

    isElement(val)

    功能：判断是否为 DOM 元素节点（nodeType === 1）。文本节点、注释节点、document、null 都返回 false。 兼容：IE9+
    签名与参数
    
melui.util.isElement(
    val   // {*} 任意值
);
// return {Boolean} 是元素节点返回 true
    示例
    
melui.util.isElement(document.body);                // true
melui.util.isElement(document.createTextNode('x')); // false  文本节点
melui.util.isElement(document);                     // false  document 节点

    3.2 对象工具

    mergeObj(...objects)

    功能：深合并多个对象，返回一个全新对象。同名属性后传的覆盖先传的；双方都是普通对象时递归合并。 兼容：IE9+
    签名与参数
    
melui.util.mergeObj(
    obj1,      // {Object} 基础对象
    obj2,      // {Object} 可传任意个，后面的覆盖前面的
    objN       // {Object} 非普通对象（数组、null、字符串等）会被整段跳过
);
// return {Object} 全新对象

// 行为约定：
// 1. 不修改任何入参对象，用户传进来的 options 不会被污染
// 2. 数组不递归合并，整体替换成一个克隆后的新数组
// 3. 返回值里的普通对象与数组都是新引用，改结果不会影响入参
    示例（参数较多，给一个合并场景）
    
var userOpts = { text: '原对象', size: 33 };
var result = melui.util.mergeObj(
    { text: '默认', size: 40, nested: { a: 1 } },
    userOpts,
    { nested: { b: 2 } }
);

// result: { text: '原对象', size: 33, nested: { a: 1, b: 2 } }
// userOpts 仍然是 { text: '原对象', size: 33 }，没有被改动

    shallowCopy(val)

    功能：浅拷贝一个普通对象，只复制第一层属性，值为引用类型的属性仍然是同一个引用。 兼容：IE9+
    签名与参数
    
melui.util.shallowCopy(
    val   // {Object} 需为普通对象；传其它类型返回空对象 {}
);
// return {Object} 新的第一层对象
    示例
    
var source = { name: 'melui', options: { size: 40 } };
var copy = melui.util.shallowCopy(source);

// copy: { name: 'melui', options: { size: 40 } }
// copy.options 与 source.options 是同一个对象：改 copy.options.size 会连带影响 source
melui.util.shallowCopy(null);    // {}
melui.util.shallowCopy([1, 2]);  // {}

    选哪一个：需要保留默认参数、又不污染调用方传入的 options，用 mergeObj；只想复制一层键值、明确知道嵌套对象要共享引用，用 shallowCopy。

    比较方式：mergeObj 每次都返回新对象，不要用 === 判断两次调用结果是否相等，需要比较内容请逐个属性判断。

    四、util 扩展包扩展模块 · 单独打包 melui-util.js

    melui-util.js 是独立产物，包含基础层与下面扩展模块的工具函数。扩展模块按模块名分组挂载，不扁平到 melui.util 顶层。

    模块职责调用前缀
    date负责日期比较、日期边界、日期偏移、星期转换、格式化与时间戳互转。全部是日期计算，不读写 DOM。melui.util.date.xxx
    format负责数字、百分比、金额、空值、中文数字与科学计数的格式转换，全部是字符串 / 数字处理，不读写 DOM。melui.util.format.xxx
    dom负责 DOM 查询、class 操作、HTML 读写、节点插入、位置尺寸、滚动、事件、textarea 自增高与阅读更多。会直接读写 DOM。melui.util.dom.xxx
    string负责 URL 参数、HTML 编解码、特殊字符处理与数值 / 时间字符串过滤，全部是字符串处理，不读写 DOM。melui.util.string.xxx
    validate负责危险字符、JSON、电话 / 邮箱、设备与浏览器、网络状态、时间格式校验。多数返回 Boolean；checkHasDangerousChars 默认会弹提示。melui.util.validate.xxx
    array负责数组去重、排序、key 集合、深比较、重复检测与相邻分组。排序函数返回新数组，不修改入参数组。melui.util.array.xxx
    random负责随机整数、数字串、字符串、随机词、随机字符与随机颜色。随机颜色支持纯随机、限定亮度和 WCAG 对比度三种模式。melui.util.random.xxx
    biz负责从文本中提取电话号码、把省市区数组去重并分组成树。melui.util.biz.xxx
    widget负责网页水印与返回顶部控件，会创建或修改 DOM。melui.util.widget.xxx

    分组规则：melui.util.date、melui.util.dom 等是模块对象；函数不会写成 melui.util.getNowTime。

    错误处理：非法入参按各函数注释返回空串、空数组、空对象、false 或 0；需要弹提示的函数会在对应条目里单独说明。

    DOM 依赖：dom 与 widget 模块需要浏览器环境；在 Node/SSR 里没有 document 时不要调用这两个模块。

    4.1 date 日期工具调用 melui.util.date.xxx

    负责日期比较、日期边界、日期偏移、星期转换、格式化与时间戳互转。全部是日期计算，不读写 DOM。

    本章示例均已写成完整调用路径，例如 melui.util.date.函数名()；melui.util.date 里的函数不会扁平到 melui.util 顶层。

    比较与判断

    compareTwoDates(dateStr1, dateStr2)

    功能：比较两个日期字符串的先后  返回：String；">" 前者晚；"<" 前者早；"=" 相同或任一无法解析
    签名与参数
    melui.util.date.compareTwoDates(
    dateStr1,   // {String} 日期 1
    dateStr2   // {String} 日期 2
);
// return {String} ">" 前者晚；"<" 前者早；"=" 相同或任一无法解析
    示例
    melui.util.date.compareTwoDates('2026-01-01', '2026-01-02') // '<'
melui.util.date.compareTwoDates('2026-01-02', '2026-01-01') // '>'
melui.util.date.compareTwoDates('2026-01-01', '2026-01-01') // '='

    isDateString(str)

    功能：是否可被 Date 解析的日期字符串（不认只有年份的 "2018"）  返回：Boolean；true 可解析；false 为空、纯数字或非法日期
    签名与参数
    melui.util.date.isDateString(
    str   // {String} 待判断值
);
// return {Boolean} true 可解析；false 为空、纯数字或非法日期
    示例
    melui.util.date.isDateString('2026-11-20') // true
melui.util.date.isDateString('2026-13-01') // false
melui.util.date.isDateString('2026')       // false

    getNumberOfDays(date1, date2)

    功能：两个日期相差的天数（后者减前者）  返回：Number；天数；date2 早于 date1 时为负数；任一参数非法返回 0
    签名与参数
    melui.util.date.getNumberOfDays(
    date1,   // {String} 开始日期
    date2   // {String} 结束日期
);
// return {Number} 天数；date2 早于 date1 时为负数；任一参数非法返回 0
    示例
    melui.util.date.getNumberOfDays('2026-01-01', '2026-01-03') // 2
melui.util.date.getNumberOfDays('2026-01-03', '2026-01-01') // -2
melui.util.date.getNumberOfDays('bad', '2026-01-01')        // 0

    当前时间

    getNowTime(options)

    功能：当前时间，按格式串返回  返回：String；格式化后的当前时间；格式串为空时使用默认格式
    签名与参数
    melui.util.date.getNowTime(
    options   // {Object} 可选配置
    // 可选字段：
    // options.zero  {Boolean} 月/日/时/分/秒是否补零
    // options.format  {String} 格式串 支持 y/M/d/H/m/s/q/S 占位符，也兼容 年-月-日、年-月、月-日
);
// return {String} 格式化后的当前时间；格式串为空时使用默认格式
    示例
    以下示例按当前时间 2026-11-20 09:30:00 说明：
melui.util.date.getNowTime()                                  // '2026-11-20 09:30:00'
melui.util.date.getNowTime({ format: 'yyyy-MM-dd' })           // '2026-11-20'
melui.util.date.getNowTime({ format: 'HH:mm' })                // '09:30'
melui.util.date.getNowTime({ zero: false })                    // '2026-11-20 9:30:0'
