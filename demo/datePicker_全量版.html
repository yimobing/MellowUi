📅 MelDatePicker 日期选择器

轻量级原生JS日期选择器插件，参考jeDate设计

✓ 兼容IE9+ ✓ 兼容Edge ✓ 移动端适配 ✓ PC端适配 ✓ 多种触发方式 ✓ 零依赖 ✓ 丰富静态方法

方式一：两种调用方式

支持 new MelDatePicker() 和 MelDatePicker() 两种方式

// 方式1：构造函数调用
var picker1 = new MelDatePicker('#demo1-1', { format: 'yyyy-MM-dd' });

// 方式2：工厂模式（无需new关键字）
var picker2 = MelDatePicker('#demo1-2', { format: 'yyyy-MM-dd' });

方式二：ID选择器触发

通过元素ID初始化，点击输入框即可弹出日期选择器

MelDatePicker('#demo2', {
    format: 'yyyy-MM-dd',
    minDate: '2020-01-01',
    maxDate: '2030-12-31'
});

方式三：Class选择器批量触发

一个实例可以绑定多个相同class的元素

MelDatePicker('.demo-class', { format: 'yyyy-MM-dd' });

方式四：data-trigger 按钮触发

在input上添加 data-trigger 属性绑定按钮ID，点击按钮触发

<input type="text" id="demo4-input" data-trigger="demo4-btn" readonly>
<button id="demo4-btn">选择日期</button>

<script>
MelDatePicker('#demo4-input', { inputTrigger: false });
</script>

方式五：inputTrigger 参数

按钮触发模式下，inputTrigger 控制输入框是否也能触发

MelDatePicker('#demo5-1-input', { inputTrigger: true });  // 输入框和按钮都能触发
MelDatePicker('#demo5-2-input', { inputTrigger: false }); // 只能按钮触发

方式六：defaultDate 默认日期

设置输入框的默认日期值

MelDatePicker('#demo6-1', { defaultDate: new Date() });
MelDatePicker('#demo6-2', { defaultDate: '2024-06-15' });

方式七：回调函数

监听选择事件，获取选中的日期

回调结果：暂未选择 
MelDatePicker('#demo7', {
    onSelect: function(date, dateStr) {
        document.getElementById('demo7-result').innerText = dateStr;
    },
    onClear: function() {
        document.getElementById('demo7-result').innerText = '已清空';
    }
});

方式八：日期范围限制

设置最小和最大可选日期

MelDatePicker('#demo8', {
    minDate: MelDatePicker.today('yyyy-MM-dd'),
    maxDate: MelDatePicker.addDays(30, 'yyyy-MM-dd')
});

方式九：confirmToClose 确定后关闭

控制选择日期后是否需要点击确定按钮才关闭控件

MelDatePicker('#demo9-1', { confirmToClose: false }); // 选择日期后直接关闭
MelDatePicker('#demo9-2', { confirmToClose: true });  // 选择日期后需点确定才关闭

静态方法：快捷日期获取

MelDatePicker 提供丰富的静态方法快速获取常用日期

// 基础日期
MelDatePicker.today()           // 今天
MelDatePicker.tomorrow()        // 明天
MelDatePicker.yesterday()       // 昨天

// 月/季/年边界
MelDatePicker.monthFirst()      // 本月第一天
MelDatePicker.monthLast()       // 本月最后一天
MelDatePicker.yearFirst()       // 本年第一天
MelDatePicker.yearLast()        // 本年最后一天

// N天/月/年前后
MelDatePicker.addDays(7)        // 7天后
MelDatePicker.addMonths(-1)     // 1个月前
MelDatePicker.addYears(1)       // 1年后

// 支持传入格式参数
MelDatePicker.today('yyyy年MM月dd日')

API 文档

MelDatePicker 提供了丰富的配置选项和方法

// 配置选项
{
    format: 'yyyy-MM-dd',      // 日期格式
    minDate: '1900-01-01',     // 最小日期
    maxDate: '2099-12-31',     // 最大日期
    defaultDate: null,         // 输入框默认日期
    trigger: 'click',          // 触发方式: click/focus
    inputTrigger: false,       // 按钮模式下输入框是否可触发
    zIndex: 9999,              // 弹层层级
    readOnly: true,            // 输入框只读
    closeOnSelected: true,     // 选择后自动关闭
    confirmToClose: false,    // 选择日期后是否需要点击确定按钮才关闭
    
    // 回调函数
    onSelect: function(date, dateStr) {},
    onOk: function(date, dateStr) {},
    onClear: function() {},
    onClose: function() {}
}
