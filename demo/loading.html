    MelUi Loading 加载转圈组件

    版本：v0.1.4 | 兼容IE9~11、移动端自适应 | melui.showLoading() 与 MelUi.showLoading() 等价（小写只是别名）

    说明：不能直接双击打开本页面（file://），浏览器会拦截模块加载，必须使用本地 HTTP 服务打开。

    原因：本页用 type="module" 直接加载 ../src/index.js，浏览器对 file:// 协议下的模块脚本做了安全拦截，必须起一个本地 http 服务，访问 http://localhost:8099/demo/loading.html。

    发布后的业务项目：只引下面「二、标准引入方式」里的两行 dist 产物，Loading 与 Spinner 已经打包进 melui 主包，不需要单独引 core，也不需要引任何 ../src 下的源码文件。

    IE9 验收：IE9 不支持 ES Module，请用打包产物验证，必须用 release/dist/melui.min.js 在 IE9 真机验证，源码的 type="module" 写法 IE9 不认。

    一、组件构成与 API 关系

    这一页演示的不是一个“转圈组件”，而是一套加载态方案：底层负责画转圈，上层负责把转圈装进遮罩、配文字、管计数。

    1.1 Spinner：只负责画转圈

    createSpinner 的作用只有一个：在指定容器里画出一个四点环，返回实例对象 { el, options, destroy }。它不创建遮罩、不显示文字、不做计数、不锁页面滚动；放在哪个容器里，就只管那个容器。

    1.2 Loading：转圈 + 遮罩 + 文案 + 计数

    showLoading 是业务入口：内部会调用 createSpinner 生成转圈，再套上遮罩、提示文字、自动 zIndex、滚动锁与调用计数。closeLoading 与它配对使用，计数归零时才销毁或隐藏浮层。isLoading 用来查询当前是否还有未关闭的 Loading。

    1.3 两者的关系

    
melui.createSpinner(el, options)          底层：只画转圈，不含遮罩与文字
        │
        │ showLoading 内部会调用它
        ▼
melui.showLoading(options)                上层：遮罩 + 转圈 + 文字 + 计数 + 滚动锁
        │
        ▼
melui.closeLoading()                      计数归零 → 销毁 / 隐藏，并解锁滚动

    为什么 createSpinner 也对外：需要无遮罩的局部转圈、想自己控制生命周期、或把转圈塞进已有弹窗时，用不到整套 Loading，直接拿底层图形即可。

    反向不成立：showLoading 打开的浮层不要手动 destroy，统一用 closeLoading 关闭，否则计数与滚动锁会残留。

    参数是共用的：Spinner 图形参数（size、color、speed、strokeWidth）两边都能传，Loading 只是在此之上多了遮罩、文字、el、zIndex、destroyOnClose。

    二、标准引入方式

    
<link rel="stylesheet" href="../dist/melui.min.css">
<script src="../dist/melui.min.js"></script>

    三、对外 API 与默认配置参数

    3.1 对外 API

    业务只调用这 4 个入口，参数全部可选；后续新增 API 在表格里加一行即可。

    API 作用 参数 返回值
    melui.showLoading(options) 打开全局或局部 Loading；重复调用只更新文字并累加计数，不重建 DOM options 对象，全部可选；也可传字符串简写 浮层根节点 HTMLElement；el 解析失败返回 null
    melui.closeLoading() 关闭一层 Loading，计数归零才销毁或隐藏，并解锁滚动 无 true 成功；计数不足返回 false 并 warn
    melui.createSpinner(el, options) 底层 API：生成转圈 DOM，不含遮罩、文字与计数，用完自己销毁 el：DOM 或选择器；options：Spinner 参数 实例对象 { el, options, destroy }；容器不存在返回 null
    melui.isLoading() 查询是否还有 Loading 未关闭；只看全局计数，不看 DOM 无 true / false

    字符串简写：melui.showLoading("加载中...") 等价于 melui.showLoading({ text: "加载中..." })。

    重要提示：多次调用 showLoading 打开加载，必须对应相同次数调用 closeLoading 才能关闭；只调一次 closeLoading 不会关掉整层浮层。

    页面跳转、全局异常等兜底场景，需要一次性关闭全部 Loading 时，可借助 isLoading() 循环关闭：

    
while (melui.isLoading()) {
    melui.closeLoading();
}

    上面的循环仅用于兜底清理；正常业务的异步请求请成对调用 showLoading / closeLoading，不要把循环当作常规关闭方式。

    3.2 Spinner 参数默认值（showLoading 与 createSpinner 共用）

    
var spinnerDefaults = {
    size: 40, // 转圈整体尺寸(可选)。数字即px，支持 数字 / "40px"。
    color: "#1677ff", // 圆点颜色(可选)。支持任意合法css颜色值。
    speed: 1, // 旋转一圈的秒数(可选)。数字越大转得越慢；IE9下无动画，本参数不生效。
    strokeWidth: 4, // 圆点直径的一半(可选)。圆点直径 = strokeWidth * 2，最大不超过 size 的一半。
    type: "ring", // 转圈类型(可选)。当前只有 ring（四点环形），预留扩展。
    customClass: "" // 追加的class(可选)。用于自定义皮肤。
};

    3.3 Loading 浮层参数默认值（在 Spinner 参数基础上扩展）

    
var loadingDefaults = {
    text: "加载中...", // 提示文字(可选)。空字符串则不渲染文字节点。
    showText: true, // 是否显示提示文字(可选)。值：true显示,false隐藏。
    mask: true, // 是否显示遮罩层(可选)。值：true显示遮罩,false只显示转圈。
    maskColor: "rgba(0,0,0,0.4)", // 遮罩背景色(可选)。mask=false时无效。
    maskOpacity: 1, // 遮罩透明度(可选)。取值0~1，只作用于遮罩，不影响转圈与文字；会和maskColor里的alpha相乘。
    textColor: "", // 文字颜色(可选)。留空时按有无遮罩自动取：有遮罩用白色，无遮罩用深色。
    el: null, // 挂载容器(可选)。null表示全屏(body)；可传DOM元素或选择器字符串，局部loading用。
    zIndex: 0, // 层级(可选)。0表示自动分配，从2000开始，每开一次加10。
    destroyOnClose: true // 关闭后是否销毁DOM(可选)。false时只隐藏，下次复用同一节点。
};

    count 计数：连续调用 showLoading 不会重建 DOM，只会更新文字并累加计数；必须调用同样次数的 closeLoading，计数归零后才销毁/隐藏并释放滚动锁。多调 closeLoading 只 warn 不抛错。

    滚动锁：全屏 Loading 会锁住 html/body 滚动并补偿滚动条宽度，关闭时恢复原滚动位置；el 局部 Loading 用 absolute 定位，不锁页面滚动。

    IE9 降级：IE9 不支持 @keyframes，转圈只显示静态四点环，遮罩、文字、滚动锁全部正常。

    createSpinner 是底层 API：第一个参数必须是容器（DOM 元素或选择器），找不到容器返回 null；它不负责遮罩、文字与计数，用完必须自己 destroy，返回结构与 destroy 的行为见第四节。

    isLoading() 只看全局计数器，不看 DOM：showLoading 后为 true，计数归零后为 false；createSpinner 生成的局部转圈不计入这个计数器，需要自己保存实例判断。

    四、createSpinner 返回的实例对象

    createSpinner 不返回 DOM 元素本身，而是一个实例对象，三个字段都有明确用途：

    
var sp = melui.createSpinner(el, options);

// sp = {
//     el:      HTMLElement,  // 转圈根节点，已 append 到容器
//     options: Object,       // 默认参数 + 你传入的参数，mergeObj 合并后的最终配置
//     destroy: function () {} // 销毁方法
// }

    
// destroy() 的行为约定
melui.createSpinner(el).destroy();

// 1. 无参数、无返回值，只做一件事：把 el 从父容器中移除
// 2. 幂等：已经移除的节点再调一次不会报错，不会重复处理
// 3. 不清空 sp.options、不重置 el 变量、不影响容器里的其它内容
// 4. 不碰 loadingCount、不碰滚动锁、不碰遮罩 —— 这些属于 showLoading / closeLoading

    el 的用途：想把转圈节点挪到别处、或单独改样式时，直接操作 sp.el；它已经是容器里的真实节点。

    options 的用途：调试或二次封装时读最终配置，比如 sp.options.speed、sp.options.color，拿到的是合并后的值而不是你传的原始对象。

    不 destroy 的后果：节点会一直留在容器里；同一个容器反复 createSpinner 会叠加多层转圈，需要先 destroy 旧的或清空容器。

    别和 closeLoading 混用：createSpinner 生成的局部转圈不进全局计数，closeLoading 管不到它；showLoading 打开的浮层也不该手动 destroy，统一用 closeLoading 关闭。

    五、调用示例

    1、纯 Spinner（createSpinner）
    渲染 3 个 Spinner，再一起销毁
    最底层的用法：往同一个容器里塞 3 个不同颜色、不同转速的转圈，2.5 秒后逐个 destroy 释放 DOM
    
var box = document.getElementById("spinner-demo");
var colors = ["#1677ff", "#52c41a", "#e8532b"];
var list = [];
var i;

for (i = 0; i < 3; i++) {
    list.push(melui.createSpinner(box, {
        size: 28,
        color: colors[i],
        speed: 1 + i * 0.3
    }));
}

setTimeout(function () {
    for (var j = 0; j < list.length; j++) {
        list[j].destroy();
    }
    list = [];
}, 2500);
    单个 Spinner 改尺寸与颜色
    createSpinner 的第一个参数是容器，第二个才是参数；容器可以传选择器字符串
    
var sp = melui.createSpinner("#spinner-demo-2", {
    size: 56,
    color: "#0b6b5f",
    strokeWidth: 6
});

setTimeout(function () {
    sp.destroy();
}, 2500);
    容器不存在时返回 null
    传了找不到的容器不会抛错，而是返回 null；业务侧可以先判断再使用，避免空指针
    
var sp = melui.createSpinner("#not-exist-box", { size: 32 });

alert(sp === null ? "容器不存在，返回 null" : "拿到了实例");
    2、基础 Loading
    最简调用
    不传参数，默认全屏遮罩 + 转圈 + "加载中..."，3 秒后自动关闭
    
melui.showLoading();
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    自定义提示文字 - 对象写法
    text 可以是任意文案，长文案会自动换行，不会撑破浮层
    
melui.showLoading({
    text: "正在校验订单数据，请稍候"
});
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    自定义提示文字 - 字符串简写
    直接传字符串，等价于 { text: "xxx" }，最省事的写法
    
melui.showLoading("正在保存配置");
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    连续调用计数
    连开 3 次，界面只有一个浮层；关 2 次仍然存在，第 3 次才真正消失并释放滚动锁
    
melui.showLoading("第 1 层任务");
melui.showLoading("第 2 层任务");
melui.showLoading("第 3 层任务");

setTimeout(function () {
    melui.closeLoading(); // 计数 3 -> 2，浮层还在
    melui.closeLoading(); // 计数 2 -> 1，浮层还在
    setTimeout(function () {
        melui.closeLoading(); // 计数 1 -> 0，浮层消失
    }, 1500);
}, 1500);
    查询加载状态 isLoading()
    打开前是 false，打开后是 true，关闭归零后再变回 false；若上面示例的 Loading 还没结束，打开前会是 true，这正是计数器在起作用
    
var before = melui.isLoading(); // 打开前：false

melui.showLoading("正在提交订单");
var during = melui.isLoading(); // 打开中：true

melui.closeLoading();
var after = melui.isLoading();  // 关闭后：false

alert("打开前：" + before + "，打开中：" + during + "，关闭后：" + after);
    3、开启遮罩
    默认遮罩（mask: true）
    mask 默认为 true，遮罩覆盖全屏、拦截点击，文字自动用白色，这是最常用的加载态
    
melui.showLoading({
    mask: true,
    text: "遮罩已开启，页面点击被拦截"
});
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    自定义遮罩颜色
    maskColor 支持 rgba，浅色遮罩下文字自动改深色，避免看不清；想反向对比可试 mask: false
    
melui.showLoading({
    maskColor: "rgba(255,255,255,0.88)",
    text: "浅色遮罩，文字自动转深色"
});
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    遮罩开启 + 指定文字颜色
    textColor 一旦传入就覆盖自动判断，转圈颜色也跟着走；适合品牌色统一
    
melui.showLoading({
    maskColor: "rgba(255,255,255,0.9)",
    textColor: "#0b6b5f",
    color: "#0b6b5f",
    text: "品牌色文字与转圈"
});
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    关闭遮罩（mask: false）
    和上面三项对照：不显示遮罩时只有转圈和文字，页面仍可操作
    
melui.showLoading({
    mask: false,
    text: "无遮罩加载，页面可继续点击"
});
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    4、转圈图形参数
    调整尺寸 size
    size 控制整体直径，圆点直径与半径同步换算，默认 40
    
melui.showLoading({
    size: 64,
    text: "size: 64"
});
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    调整颜色 color
    color 同时作用于四个圆点；遮罩上的文字默认跟随该颜色
    
melui.showLoading({
    color: "#e8532b",
    text: "color: #e8532b"
});
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    调整转速 speed
    speed 是转一圈的秒数，数字越小越快；IE9 无动画，该参数不生效
    
melui.showLoading({
    speed: 0.5,
    text: "speed: 0.5 快速"
});
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    调整圆点粗细 strokeWidth
    圆点直径 = strokeWidth * 2，超过 size 一半会被自动收敛，不会画出边界
    
melui.showLoading({
    strokeWidth: 8,
    text: "strokeWidth: 8"
});
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    隐藏文字 showText: false
    只留转圈不显示文字，适合空间很小或文案无意义的场景
    
melui.showLoading({
    showText: false
});
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    5、局部 Loading
    el 传选择器
    转圈只覆盖该容器、改用 absolute 定位，宿主 position 会被临时改成 relative，关闭后还原，且不锁页面滚动
    这里是 #loading-box 容器，局部 Loading 只盖住这块区域
    
melui.showLoading({
    el: "#loading-box",
    text: "容器内加载中..."
});
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    el 传 DOM 元素
    直接传元素对象，效果与选择器一致；组件内部调用时用这种写法更稳，不受 id 变化影响
    
melui.showLoading({
    el: document.getElementById("loading-box"),
    text: "传 DOM 元素"
});
setTimeout(function () {
    melui.closeLoading();
}, 3000);
    6、销毁策略
    destroyOnClose: false 复用 DOM
    关闭只隐藏节点，不销毁 DOM；连续开关时不会重建，适合列表页高频调用
    
melui.showLoading({
    destroyOnClose: false,
    text: "关闭后只隐藏，节点保留复用"
});
setTimeout(function () {
    melui.closeLoading();
}, 2000);
    destroyOnClose: true（默认）
    关闭即销毁 DOM、清空引用，不会留下隐藏节点；单次加载场景用默认值最省内存
    
melui.showLoading({
    destroyOnClose: true,
    text: "关闭即销毁，节点不保留"
});
setTimeout(function () {
    melui.closeLoading();
}, 2000);
