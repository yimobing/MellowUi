MelUi Table 表格控件 v1.x · 原生JS

数据驱动的录入 / 展示双用表格，兼容 IE9 / IE10 / IE11 / Edge，无第三方依赖。

1功能概览

核心优势

IE9+ 全兼容 纯原生 JS 实现，不依赖 jQuery / 框架；不用 let / const / 箭头函数 / 模板字符串，可直接跑在老旧内网环境。
数据驱动，DOM 只是投影 业务数据统一存放在 DataStore，读取、保存、导出全部走数据层，不从 DOM 反查 input 的值，大数据量操作更快。
原生 table-layout:fixed 列宽由浏览器原生表格布局计算，避免 JS 反复测量 DOM 造成重排重绘。
插件化分层 核心层只保留表格骨架，序号、状态列、多选、排序、分页、合计、导出全部按需启用，不用的插件不加载。
录入 / 展示双用 同一套组件既能做纯文本展示表，也能做大量 input / radio / checkbox 的录入表。
完整销毁机制 destroy() 清理 resize 监听、表身滚动监听、恢复 body 样式，避免内存泄漏。

基础表格能力

  1. 传入 columns 配置列，支持标题 title、副标题 subtitle、字段 field、列宽 width、对齐 align（left / center / right）。
  2. 列配置同时支持：readonly 只读、disabled 禁用、defaultValue 新增行默认值、required 必填、unique 唯一值、type 数据类型（int / float）、digit 小数位数、formatter 显示格式化。
  3. 传入数组 data 渲染表格；提供新增行、删除行、清空、整表替换等 API。
  4. 表格外观：边框 bordered、斑马纹 stripe、行悬浮高亮 hoverHighlight。
  5. 单元格渲染：纯文本、单行输入框、多行文本域、按钮、radio、checkbox；单元格文字溢出省略。
  6. 合计行、序号列、状态列、多选列、表头排序、分页、Excel 导出（均以插件形式启用）。
  7. 左侧连续 N 列冻结 fixedLeftColumns；列宽自适应 fitWidth。
  8. 窗口自适应：fitViewport 视口高度自适应 + 底部留白 viewportBottomGap + resize 节流刷新。
  9. 新增行自动滚动定位 + 自动聚焦第一个可输入文本框（自动跳过 checkbox / radio / button）。

最小示例

<div id="table-box"></div>

    <script>
    // 1. 列配置：一列对应一个字段
    var columns = [
        {field: "name", title: "名称", width: 160, renderer: "input", required: true, align: "left"},
        {field: "price", title: "单价", subtitle: "(元)", width: 120, renderer: "input", type: "float", digit: 2, align: "right"}
    ];

    // 2. 行数据：对象数组，每一对象就是表格中的一行
    //    对象里的 key 必须与 columns 中的 field 一一对应（name 对应第一列，price 对应第二列）
    var data = [
        {name: "测试项A", price: 100.00},
        {name: "测试项B", price: 200.50}
    ];

    // 3. 初始化
    var table = MelUi.Table(options); // options 主配置项，Object 类型
    // eg.
    var table = MelUi.Table({
        el: "#table-box",
        columns: columns,   // 表头 + 每列渲染方式
        data: data,        // 表身每一行的数据
        rowHeight: 40,
        bordered: true,
        stripe: true,
        plugins: [
            "SerialNo",
            {name: "Pagination", pageSize: 20}
        ]
    });
    </script>
data 与 columns 的关系： data 是行数据数组，每个元素是一行的数据对象； 对象里的 key 与 columns 中每一项的 field 对应。 上例中第一列 field: "name" 会读取每一行的 name 值渲染，第二列读取 price。 如果某行缺少某字段，会按该列的 defaultValue 补默认值（未配置则显示空）。

3主配置项（options）

下表中 必填 为必须传入，可选 未传时取默认值。

基础

参数类型默认值说明
elString / HTMLElement—必填 表格挂载节点，传 CSS 选择器字符串或 DOM 元素。
columnsArray[]必填 列配置数组，每一项描述一列（详见第 4 节）。
dataArray[]必填 表格数据，对象数组，每个对象对应一行。

表格上下额外区块

参数类型默认值说明
extraBeforeString / Function空字符串 表格上方额外内容。String 直接作为html渲染；Function 以表格实例为参数，返回html字符串。取值或返回值为空则不渲染该区块。eg. extraBefore: function(tb) { return ' 表格前面的内容'}
extraAfterString / Function空字符串 表格下方额外内容(可选)。用法同 extraBefore。

外观

参数类型默认值说明
borderedBooleantrue是否显示单元格边框。
stripeBooleanfalse是否隔行变色（斑马纹）。
hoverHighlightBooleantrue鼠标悬停行是否高亮。
showSelectAllBooleantrue多选列表头是否显示全选复选框（配合 Checkbox 插件）。
rowHeightNumber40行高，单位 px。
headerHeightNumber / 'auto''auto'表头高度。'auto' 由内容自动撑开；传数值时使用固定高度（px）。
fixedLeftColumnsNumber0左侧连续冻结列数量，0 表示不冻结，1 表示冻结第 1 列。

布局与尺寸

参数类型默认值说明
fitViewportBooleantrue是否垂直适配视口。true 时 bodyHeight、el 自定义高度失效，表格自动占满页面剩余高度且页面不出现垂直滚动条。同一个页面只能最多一个表格开启 fitViewport，如有多个表格请关闭 fitViewport 。
viewportBottomGapNumber16仅 fitViewport=true 生效。表格与视口底边之间预留的间隙（px），露出 body 背景色。
bodyHeightNumber0表身固定高度（px）。0 表示不限制，由 el 节点控制。fitViewport=true 时本参数无效；fitViewport=false 且 >0 时会把 el 高度强制为 auto!important。
fitWidthBooleanfalsefalse 为固定列宽模式，使用 columns 的 width(px)；true 为弹性模式，列宽总和小于容器时按 width 权重拉伸填满，大于容器时不拉伸并出现横向滚动条。

分页

参数类型默认值说明
remotePagingBooleanfalsefalse：前端本地分页，一次性传全部 data，组件内部切片；true：后端远程分页，翻页 / 改每页条数时触发 onPageChange，由业务请求后端后 setData 回填。
totalNumber0总记录数，仅 remotePaging=true 生效，由外部传入后端总条数，组件据此渲染分页栏。
enableRemotePagingFallbackBooleantrue是否兜底后端远程分页，仅 remotePaging=true 生效。后端 total=0 或 total 小于当前返回列表条数时：true 则组件自动降级，用当前这批数据前端本地分页；false 则严格信任后端 total，不自动切换。
标准分页接口建议设 false；接口本身不支持一次性返回总记录数时设 true。
addRowModeString'currentPage'新增行插入位置，仅 remotePaging=false 时有效。
'currentPage'：插入当前页数据集合，配合 addRow 的 position 控制当前页首 / 尾；
'global'：插入全局原始数据数组首 / 尾。
remotePaging=true 时本参数无效（自动按全局处理）。

插件与事件

参数类型默认值说明
pluginsArray[]插件数组。支持字符串简写（启用 + 默认配置）和对象简写（启用 + 自定义配置），详见第 6 节。
eventsObject{}事件回调集合，如 onCellClick / onCellChange / onRowClick / onSelectChange / onRowAdd / onRowDelete / onPageChange，详见第 9 节。

实例只读属性

属性类型默认值说明
table.isDestroyedBoolean—表格实例是否已销毁。true = 实例已销毁，此时不可调用实例API，false 表格实例正常使用。
table.isFallbackPagingBoolean—当前是否处于「降级兜底分页」状态。true 表示后端 total 不可信、组件在用当前这批数据做前端本地分页；业务应在 onPageChange 中据此判断：true 时不要再请求后端，false 时才请求后端。
每次 setData / setRows 后自动重新计算。

4列配置（columns）

columns 中每一项描述表格的一列，字段与渲染方式都写在同一个对象里。

字段类型默认值说明
fieldString—必填 字段名，数据读写唯一标识，必须与 data 对象中的 key 对应。内部列以 _ 开头（如 _serialNo / _state / _checkbox）。
titleString—必填 列标题，显示在表头。
subtitleString''列副标题，显示在标题下方的小字，如 "(元)"、"(㎡)"。
widthNumber—列宽（px）。table-layout:fixed 模式下由该值决定列宽。
alignString'left'单元格水平对齐：'left' / 'center' / 'right'。
rendererString'text'单元格渲染器名称，可选 'text' / 'input' / 'textarea' / 'radio' / 'checkbox' / 'button'，或自定义渲染器名（见第 5 节）。不填则用 text。
readonlyBooleanfalse整列只读。input / textarea / radio 渲染时加 readonly 属性，不可编辑。
disabledBooleanfalse整列禁用。input / textarea / radio / button 渲染时加 disabled 属性。
defaultValueAny—新增行时该列的默认值。行数据中该字段为 undefined 时自动填入。
requiredBooleanfalse必填标记。input / textarea 会生成"请输入xxx"的 placeholder；validate() 会校验该列不能为空。
uniqueBooleanfalse唯一值标记。validateUnique() 会校验该列在整表中不允许重复。
typeString—数据类型过滤，支持 'int'（只允许整数和负号）/'float'（只允许数字、小数点和负号）。输入时实时过滤非法字符。不填则不过滤。
digitNumber—小数位数。input 渲染时按该值 toFixed 显示，如 2 表示保留两位小数。配合 type:'float' 使用。
formatterFunction—显示格式化函数 function(value, rowData){ return 显示文本 }。只影响显示与导出，不修改原始数据。text / radio 渲染器会调用。
radioOptionsObject{yes:'1', no:'0'}radio 渲染器专用：两个选项的值，如 {yes:'1', no:'0'}。显示文字可通过 formatter 定制。
buttonTextString'按钮'button 渲染器专用：按钮文字。
buttonIconString''button 渲染器专用：Font Awesome 图标名，渲染为 <i class="fa fa-图标名">。
提示：插件会自动往 columns 里插入内部列（SerialNo 插 _serialNo，Checkbox 插 _checkbox，StateColumn 插 _state）。 如果你的 columns 是第一列就要冻结且同时启用了这些插件，冻结数量要把插件列算进去。

5单元格渲染器

渲染器负责把「值 + 列配置 + 行数据」变成一个单元格的 HTML。内置 6 种，全部注册在 MelUi.Table.cellRenderers 上。

renderer 值渲染结果说明与相关列配置
'text'纯文本 <span>默认渲染器。支持 formatter 格式化显示，空值显示为空。
'input'单行输入框支持 readonly / disabled / required(placeholder) / digit(小数位) / type(输入过滤)。
'textarea'多行文本域支持 readonly / disabled / required(placeholder)。
'radio'是 / 否 单选按钮组用 radioOptions 指定两个值；显示文字可用 formatter 定制；支持 readonly / disabled。
'checkbox'勾选框（多选/单选）主要在 Checkbox 插件的选择列使用； Checkbox 插件配置 mode:'single' 时渲染成radio，否则 checkbox。
'button'操作按钮用 buttonText 设置文字、buttonIcon 设置图标；支持 disabled。

自定义渲染器

往 MelUi.Table.cellRenderers 上注册一个函数即可，函数签名 function(value, column, rowData)，返回 HTML 字符串；然后在 columns 的 renderer 里填这个名字。

// 注册自定义渲染器：金额显示为红色，并带两位小数
    MelUi.Table.cellRenderers.money = function(value, column, rowData) {
        var num = parseFloat(value);
        var text = isNaN(num) ? '' : num.toFixed(column.digit || 2);
        return '<span style="color:#c0392b;">' + text + '</span>';
    };

    // 列配置里使用
    var columns = [
        {field: "amount", title: "金额", width: 120, renderer: "money", digit: 2, align: "right"}
    ];
注意：自定义渲染器返回的 HTML 会被直接写入单元格，业务数据若来自用户输入，请先做转义，避免 XSS。

6插件机制

核心层只负责数据、渲染、事件；扩展能力全部通过 plugins 数组注册。插件之间通过事件总线通信，不直接互相调用。

两种注册写法

写法一：字符串简写 —— 只写插件名，使用插件默认配置。

plugins: [
        'SerialNo',          // 启用序号列，全部用默认参数
        'StateColumn',       // 启用状态列
        'Export'             // 启用导出
    ]

写法二：对象简写 —— 用 name 指定插件名，其余属性作为该插件的配置项。

plugins: [
        {name: 'SerialNo', width: 60},
        {
            name: 'Pagination',
            pageSize: 20,
            pageMode: 'list',
            position: 'fixed',
            align: 'center'
        },
        {name: 'Checkbox', width: 60, mode: 'multi'}
    ]
说明：两种写法完全等价，可混用。插件名就是全局注册表 MelUi.Table.plugins[插件名] 的键，例如 'SerialNo' 对应 MelUi.Table.plugins.SerialNo。 插件按数组顺序依次初始化；SerialNo / Checkbox / StateColumn 会往 columns 里插入列，因此它们与 columns 的先后关系会影响列顺序（默认插在最前 / 最后，见各插件说明）。

内置插件一览

插件名作用依赖 / 说明
SerialNo最前面插入序号列按当前页可见行计算序号；远程分页时跨页连续
Checkbox最前面插入多选 / 单选列配合 getSelectedData / selectAll 等 API
StateColumn插入行状态列（新增 / 修改 / 已保存）读取行 _status；配合 getDirtyData / markSaved
Sort表头点击排序修改数据源顺序；支持仅当前页排序
Pagination底部分页栏本地 / 远程分页；支持兜底降级
Summary底部合计行对指定字段求和
HeaderMerge合并表头对表头进行二级、三级、四级..合并，建议最多到三级
Export导出 Excel（.xls）读取数据源导出，不遍历 DOM

7插件详解

7.1 SerialNo · 序号列

在表格最前面插入一列序号。增删行、翻页后自动重排；远程分页时按「页码 + 页容量」计算，跨页连续。

参数类型默认值说明
widthNumber50序号列宽度（px）。
showNewRowSerialNumberBooleanfalse新增行是否显示序号。false：新增行序号为空，便于一眼识别是新增行，且不占位（原有行序号不偏移）；true：新增行正常显示序号。
plugins: [
        'SerialNo',
        // 或自定义
        {name: 'SerialNo', width: 60, showNewRowSerialNumber: false}
    ]

7.2 Checkbox · 多选 / 单选列

在表格最前面插入选择列。多选模式渲染 checkbox，单选模式渲染 radio 并自动互斥。

参数类型默认值说明
widthNumber60选择列宽度（px）。
modeString'multi''multi' 多选（checkbox，表头有全选框）；'single' 单选（radio，选中某一行则其它行自动不选中，表头无全选框）。
// 多选
    plugins: [{name: 'Checkbox', width: 60, mode: 'multi'}]

    // 单选
    plugins: [{name: 'Checkbox', width: 60, mode: 'single'}]

    // 配套 API
    table.getSelectedData();   // 获取选中行数据
    table.selectAll();         // 全选（单选模式静默忽略）
    table.selectNone();        // 全不选
    table.invertSelect();      // 反选
    table.setSelectedKeys([0, 2, 4]); // 按行索引设置选中
    table.clearSelection();    // 清空选中

7.3 StateColumn · 状态列

插入一列展示行状态：新增（i）、修改（u）、已保存（s）。新增行自动标为「新」，编辑单元格自动变「改」，调用 markSaved 后变「已保存」。

参数类型默认值说明
widthNumber60状态列宽度（px）。
newTextString'新'新增状态显示文字。
unsaveTextString'改'已修改未保存状态显示文字。
savedTextString''已保存状态显示文字，默认空字符串（不显示）。
columnPositionString'behind''behind'：状态列在所有数据列最后面；'front'：状态列插在最前面（在 checkbox / 序号列之前；没有这两列时在数据第 1 列前）。
plugins: [
        {
            name: 'StateColumn',
            width: 60,
            newText: '新',
            unsaveText: '改',
            savedText: '已保存',
            columnPosition: 'behind'
        }
    ]

    // 配套 API
    table.getDirtyData();        // 获取新增 + 修改的行
    table.markSaved(0);          // 标记第 0 行为已保存
    table.markSaved('all');      // 标记全部行为已保存

7.4 Sort · 表头排序

点击表头进行升序 / 降序切换，无排序箭头再点一次切换方向。只修改数据源顺序，不重建表头。

参数类型默认值说明
defaultFieldString''初始化时默认排序列的字段名，空表示不默认排序。
defaultOrderString'asc'默认排序方向：'asc' 升序 / 'desc' 降序。
sortCurrentPageOnlyBooleanfalse是否只对当前页排序。仅 remotePaging=false 时有效；remotePaging=true 时本参数无效，强制全量排序。
true：只排序当前页切片区间并回填该区间，其他页数据顺序不变，排序后数据不会跑到其他页；
false：对整个数据源排序，排序后重新分页切片。
plugins: [
        {name: 'Sort', defaultField: 'scjj', defaultOrder: 'desc', sortCurrentPageOnly: true}
    ]
排序事件：排序完成后排序插件抛出的内部事件名是 sortChange，回调参数 {field, order}。 监听请用 table.on('sortChange', fn)。

7.5 Pagination · 分页

底部分页栏，支持数字列表 / 下拉两种模式，支持本地分页、远程分页，以及后端 total 异常时的兜底降级。

参数类型默认值说明
pageSizeNumber10每页条数。
pageModeString'list''list'：数字页码按钮；'select'：页码下拉选择。
pageListSizeNumber5数字列表模式显示几个页码按钮。
positionString'bottom'分页栏位置：'bottom' 表格下方 / 'top' 表格上方 / 'fixed' 固定页面底部。
alignString'right'分页内容对齐：'left' / 'center' / 'right'。
showQuickJumperBooleantrue是否显示「跳至 __ 页」的页码快速跳转下拉。

远程分页 + 兜底降级示例

// 标准后端分页接口：关闭兜底，严格信任后端 total
    var table = MelUi.Table({
        el: '#table-box',
        columns: columns,
        data: [],
        remotePaging: true,
        total: 100,
        enableRemotePagingFallback: false,
        plugins: [{name: 'Pagination', pageSize: 20}],
        events: {
            onPageChange: function(data) {
                // data = {curpage: 当前页, pagesize: 每页条数}

                // 仅后端远程分页(remotePaging = true)才请求后端且兜底降级时不请求后端
                // 可使用setData回填数据
                if (table.options.remotePaging && !table.isFallbackPaging) {
                    // 标准远程分页：请求后端，把返回的当页数据回填
                    requestList(data.curpage, data.pagesize, function(res) {
                        table.setData(res.list); // 使用setData回填
                    });
                }
            }
        }
    });

    // 后端接口不支持返回总记录数：开启兜底
    var table2 = MelUi.Table({
        el: '#table-box2',
        columns: columns,
        data: allData,
        remotePaging: true,
        total: 0, // 这里本应返回总记录数，但如果是0或小于当前列表记录数的值，则设置enableRemotePagingFallback = true 时会开启兜底。兜底的意义：虽然后端返回数据错误，但前端会帮忙矫正过来，比如后端总记录数返回0，则分页栏上不会显示“共0条”，分页也不会按pagesize参数来分页，而是会显示当前列表实际的条数，分页页码显示1页。
        enableRemotePagingFallback: true,
        plugins: [{name: 'Pagination', pageSize: 20}],
        events: {
            onPageChange: function(data) {
                if(table2.options.remotePaging == false) return;
                // 处于兜底降级时：组件内部已对当前数据做前端切片，切勿再请求后端覆盖数据
                if (table2.isFallbackPaging) return;
                // 后端 total 恢复正常后才请求后端
                requestList(data.curpage, data.pagesize, function(res) {
                    table2.setData(res.list);
                });
            }
        }
    });

9事件

事件总线 eventBus 统一派发。表格类事件既可以在初始化时用 events 配置，也可以用实例 on() 动态监听。

事件列表

事件名events 配置里的函数名回调参数触发时机
renderedonRendered{rows,total,pageNo,pageSize}表格完成一次整体渲染后触发。适合在渲染完成后做二次处理（如调整列宽、定位）。 参数说明：rows 当前页渲染行数据； total 分页的列表数据总记录数（按remotePaging+enableRemotePagingFallback规则计算）； pageNo 分页的页码； pageSize 分页的每页条数。
rowAddonRowAdd{rowData, rowIndex}新增行完成后触发。
rowDeleteonRowDelete或onDeleteRow{rowIndex, rowData}删除行完成后触发。
cellClickonCellClick{rowData, cell:{rowIndex, field, element}}点击单元格时触发（任何列都会触发）。
cellChangeonCellChange{rowIndex, field, newValue, oldValue}单元格值发生变化时触发：用户输入、代码 setCellValue / setRowData 均会触发。
rowClickonRowClick{rowData, rowIndex}点击行内任意单元格时触发。
selectChangeonSelectChange{selectedRows}选中行变化时触发（需 Checkbox 插件）。
sortChangeonSort{field, order}排序完成时触发（需 Sort 插件）。order 为 'asc' / 'desc'。
pageChangeonPageChange{curpage, pagesize}翻页或切换每页条数时触发（需 Pagination 插件）。
两种方式的对应关系： events 里写 onXxx，对应 事件监听table.on('xxx')。 例如 events: onCellChange ↔ table.on('cellChange')；events: onRowAdd ↔ table.on('rowAdd')。
排序例外：events 中的 onSort 是预留映射，排序插件实际抛出的事件名是 sortChange，请用 table.on('sortChange', fn) 进行事件监听。
⚠️重要时序提醒： 如果不在events里写事件，而是使用 table.on('事件名', fn) 进行事件监听，则事件监听需要先注册好，再执行操作。
❌错误写法：把 table.on('rowAdd', 回调) 写在按钮点击函数内部、table.addRow() 的后面。
执行顺序：先执行新增行 table.addRow()，立刻抛出 rowAdd 事件；这时还没有注册监听，本次新增的事件直接错过，收不到回调。多次点击还会重复注册多份监听，出现重复打印。 
// 错误示例：on写在点击函数里面
    function btnAddClick(){
        table.addRow({name:'测试'},'first');
        // 事件已经触发完毕，才注册监听，本次事件接收不到
        table.on('rowAdd',function(e){
            console.log('新增行',e); // 这里是接收不到的
        })
    }

✅正确写法：table.on() 写在按钮点击函数外面，表格创建完成之后只注册一次；点击函数里面只调用 addRow() 执行业务动作。 
// 正确示例：on写在函数外部
    var table = new MelUi.Table.Core({...});
    // 表格初始化完成，提前注册监听（只写一次）
    table.on('rowAdd',function(e){
        console.log('新增行',e); // 这里可以接收到
    });
    // 按钮点击函数内部只做新增，不要再写 table.on
    function btnAddClick(){
        table.addRow({name:'测试'},'first');
    }

两种监听方式（以 pageChange 为例）

方式一：初始化时通过 events 配置（事件名前面加 on）。

var table = MelUi.Table({
        el: '#table-box',
        columns: columns,
        data: data,
        plugins: ['Pagination'],
        events: {
            onPageChange: function(data) {
                console.log('页码：', data.curpage, '每页条数：', data.pagesize);
            }
        }
    });

方式二：实例 on() 动态监听（事件名不加 on）。

table.on('pageChange', function(data) {
        console.log('页码：', data.curpage, '每页条数：', data.pagesize);
    });

10注意事项

  1. 数据以数据层为准。读取业务数据请用 getData() / getRowData() / getDirtyData()，不要遍历 DOM 读取 input 的 value。
  2. 不要直接改内部对象。直接改 table.dataStore.rows 不会触发重绘；请用 setCellValue / setRowData / setData 等 API。
  3. 列宽是固定 px。基于 table-layout:fixed，不支持按内容自适应列宽；需要铺满容器用 fitWidth:true 按 width 权重弹性拉伸。
  4. fitViewport 会改 body 样式。开启后会设置 body 的 overflow-y:hidden，destroy() 时自动恢复；同一页面不要多个表格同时开启 fitViewport。
  5. remotePaging=true 时 addRowMode 无效。远程分页下统一按全局数据处理。
  6. 兜底降级判断。remotePaging=true 且 enableRemotePagingFallback=true 时，后端 total 不可信会自动降级为前端本地分页。此时 onPageChange 里务必用 table.isFallbackPaging 判断：为 true 时不要再请求后端，否则会把组件已经切好的数据覆盖掉。
  7. 新增行聚焦。新增行会自动聚焦行内第一个 text / password / textarea 输入框，checkbox / radio / button / hidden 会被跳过；行内没有可输入文本控件时静默不聚焦。内部有 30ms 延时兜底，极端卡顿环境可能偶发失效。
  8. 插件列会影响列顺序。SerialNo / Checkbox 插在最前，StateColumn 默认插在最后；使用 fixedLeftColumns 冻结时要把这些插件列一起算进冻结数量。
  9. IE9 环境。组件内部已规避 let / const / 箭头函数 / 模板字符串 / classList / dataset 等；业务代码同样不要使用 ES6+ 语法。
  10. 页面卸载必须 destroy。SPA 路由切换、弹窗关闭、容器复用前调用 table.destroy()，避免 resize / scroll 监听泄漏。
  11. 自定义渲染器注意 XSS。返回的 HTML 直接写进单元格，用户输入内容请先转义。
