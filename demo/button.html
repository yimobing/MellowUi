二、高级用法

1、尺寸 size large / default / small / mini 不加尺寸修饰符为default默认尺寸。 
<button type="button" class="mel-btn mel-btn--primary mel-btn--large">large 大按钮</button>
<button type="button" class="mel-btn mel-btn--primary">default 默认</button>
<button type="button" class="mel-btn mel-btn--primary mel-btn--small">small 小按钮</button>
<button type="button" class="mel-btn mel-btn--primary mel-btn--mini">mini 极小</button>
2、块级按钮 block mel-btn--block 宽度100% 块级按钮占满父容器宽度，多个按钮会各自独占一行，常用于弹窗底部、移动端。


<div style="width:320px;">
  <button type="button" class="mel-btn mel-btn--primary mel-btn--block">block 主要按钮</button>
  <button type="button" class="mel-btn mel-btn--success mel-btn--block">block 成功按钮</button>
  <button type="button" class="mel-btn mel-btn--info mel-btn--block">block 信息按钮</button>
</div>
3、禁用状态 disabled属性 + mel-btn--is-disabled 组件输出：同时渲染原生 disabled 属性与 mel-btn--is-disabled class；实现原生不可点击 + hover显示not‑allowed光标。 
<button type="button" disabled class="mel-btn mel-btn--primary mel-btn--is-disabled">primary 禁用</button>
重要：必须带上原生disabled属性，仅class无法阻止点击。
4、加载状态 mel-btn--loading mel-btn--loading仅为视觉样式，业务JS实现加载时，必须同步设置 disabled 属性，阻止重复点击。 
<button type="button" disabled class="mel-btn mel-btn--primary mel-btn--loading">primary 加载中</button>
重要：业务实际使用，loading状态务必加上disabled属性。

三、API 类名速查表

1、按钮类名说明
类名 说明
mel-btn按钮根基础类，必须存在
mel-btn--default默认次要按钮（灰色）
mel-btn--primary主要按钮（蓝色，主操作）
mel-btn--success成功按钮（绿色）
mel-btn--info信息按钮（灰蓝色）
mel-btn--warning警告按钮（橙色）
mel-btn--danger危险删除按钮（红色）
mel-btn--text文本按钮，无边框背景
mel-btn--outline描线变体，透明背景，hover淡蒙层，搭配主题类
mel-btn--plain朴素变体，常态浅底色，hover实色反白，搭配主题类
mel-btn--round胶囊大圆角按钮
mel-btn--large大尺寸按钮 height:42px
mel-btn--small小尺寸按钮 height:28px
mel-btn--mini极小按钮 height:24px
mel-btn--block块级按钮，width:100%
mel-btn--is-disabled禁用配套class，配合disabled属性，提供not‑allowed光标
mel-btn--loading加载中视觉样式，仅UI，需配合disabled属性
HTML属性注意：
1、普通操作按钮：<button type="button" class="mel-btn ...">xxx</button>
2、表单真正提交：才使用 <button type="submit">提交</button>
3、禁用状态：组件同时输出disabled属性 + mel-btn--is-disabled类。
