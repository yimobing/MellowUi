<!-- moderate 适中 10px（列表页、中等密度） -->
<div class="mel-row mel-row--type-moderate">
    <div class="mel-col mel-span-6">...</div>
</div>

<!-- compact 紧凑 5px（工作台、弹窗内部、高密度查询栏） -->
<div class="mel-row mel-row--type-compact">
    <div class="mel-col mel-span-6">...</div>
</div>
注意： mel-row--type-* 会给当前 mel-row 加上 margin-bottom（多个 mel-row 兄弟之间的间距）。 末尾多余的 margin-bottom 由业务自行处理，框架不做 :last-child 清除。
禁止混用：type 修饰符不要与独立的 mel-row--col-gap / mel-row--row-gap / mel-row--space 同时使用，避免样式叠加错乱。
极端特殊场景：如需 1px / 2px 等不在四套 type 之内的间距，移除 type 修饰符，业务自行写局部 CSS 或行内 style。

分栏偏移

通过 mel-offset-N 可以指定列的偏移量（N 为 0~23）。 例如 mel-offset-6 表示该列向右偏移 6 个栅格单位（即 25%）。

mel-span-6
mel-span-6, mel-offset-6
mel-span-4, offset-4
mel-span-4, offset-8
<!-- 第一列占6份，第二列占6份并向右偏移6份（共24份） -->
<div class="mel-row">
    <div class="mel-col mel-span-6">mel-span-6</div>
    <div class="mel-col mel-span-6 mel-offset-6">mel-span-6, mel-offset-6</div>
</div>

<!-- offset 可以叠加使用 -->
<div class="mel-row">
    <div class="mel-col mel-span-4 mel-offset-4">mel-span-4, offset-4</div>
    <div class="mel-col mel-span-4 mel-offset-8">mel-span-4, offset-8</div>
</div>
注意： mel-offset-N 建议在不带 mel-row--type-* / mel-row--col-gap 的 mel-row 上使用。 若开启间距，col 会带 padding，百分比 margin-left 的 offset 会出现对齐偏差。

表单布局 - 查询模式

mel-form-item--search 适用于页面顶部的查询条件区。 标签区宽度自适应内容，与控件同一行排列；控件区占满标签以外的剩余宽度。

默认：标签与控件同行

供应商名称
联系人
所在地区
创建时间

响应式：小视口自动上下堆叠

当浏览器视口宽度小于 768px 时，mel-form-item--search 自动切换为标签在上、控件在下的上下堆叠布局，无需业务手写响应式。 缩小浏览器窗口即可看到效果。

容器级智能堆叠（需引入 mel-layout.js）

CSS 媒体查询只能判断浏览器视口宽度，无法判断某个表单项自身容器有多宽。 例如 1920px 大屏下，某个 col 分配的空间很窄（如 mel-span-4），此时 input 会被挤压，但 CSS 媒体查询不会触发。 引入可选增强脚本 mel-layout.js 后，脚本会检测每个 search 表单项的自身容器宽度，小于阈值（默认 220px）时自动追加 mel-form-item--stack 实现上下堆叠。 

<!-- 查询模式：hd 自适应宽度浮动左，bd overflow:hidden 占剩余宽度 -->
<div class="mel-row mel-row--type-default">
    <div class="mel-col mel-span-6">
        <div class="mel-form-item mel-form-item--search">
            <div class="mel-form-item__hd">供应商名称</div>
            <div class="mel-form-item__bd">
                <input type="text" class="mel-form-ctrl" placeholder="请输入">
            </div>
        </div>
    </div>
    <!-- 更多查询条件... -->
</div>

<!-- 手动强制堆叠（兜底：大屏下容器过窄时业务手动添加） -->
<div class="mel-form-item mel-form-item--search mel-form-item--stack">
    <div class="mel-form-item__hd">窄容器条件</div>
    <div class="mel-form-item__bd">
        <input type="text" class="mel-form-ctrl">
    </div>
</div>
<!-- 引入可选增强脚本，实现容器级智能堆叠 -->
<script src="dist/mel-layout.js"></script>

<!-- 自定义堆叠阈值（可选，在引入脚本前设置） -->
<script>
    window.MEL_LAYOUT_STACK_THRESHOLD = 200; // 单位px，默认220
</script>
兼容说明： 受 IE9 约束，CSS 响应式断点基于浏览器视口宽度，非表单项自身容器宽度。 如需基于容器宽度智能堆叠，请引入 mel-layout.js（IE9 下降级为 resize + 节流轮询）。 不引入脚本时，search 表单项回退到 CSS @media(max-width:768px) 视口响应式。

必填星号位置

必填星号（mel-form-item__required）的位置由 HTML 书写顺序控制，CSS 只统一星号样式（红色、margin）。 支持三种位置：标签文字前、标签文字后、输入框后。

*星号在文字前
星号在文字后*
星号在输入框后
* 
<!-- 前置：星号在标签文字前（现代表单最常用） -->
<div class="mel-form-item__hd">
    <span class="mel-form-item__required">*</span>供应商名称
</div>

<!-- 后置：星号在标签文字后 -->
<div class="mel-form-item__hd">
    供应商名称<span class="mel-form-item__required">*</span>
</div>

<!-- 输入框后：星号在控件右侧 -->
<div class="mel-form-item__bd">
    <input type="text" class="mel-form-ctrl">
    <span class="mel-form-item__required">*</span>
</div>

类名速查表

栅格系统

mel-row                  栅格行（flex + IE9 float 降级，默认自动换行）
mel-col                  栅格列
mel-span-1 ~ mel-span-24 列占比（N/24 * 100%）
mel-offset-0 ~ mel-offset-23 列偏移（左侧 margin N/24*100%）

【主推】一套类同时控制全套间距：
mel-row--type-default    默认 20px（普通后台表单）
mel-row--type-loose      宽松 15px（详情页、大卡片）
mel-row--type-moderate   适中 10px（列表页、中等密度）
mel-row--type-compact    紧凑 5px（工作台、弹窗内部、高密度查询栏）

【备选】独立间距修饰符（不与 type 同时使用）：
mel-row--col-gap         仅列间距 20px
mel-row--row-gap         仅row内部col换行垂直间距 20px
mel-row--space           仅mel-row自身margin-bottom 20px

表单布局

mel-form-item            表单单元（一个单元 = 标签区 + 控件区）
mel-form-item__hd        标签头部（head）
mel-form-item__bd        控件主体（body）
mel-form-item--edit      编辑模式（hd固定110px右对齐，bd占剩余）
mel-form-item--search    查询模式（hd自适应，默认与bd同行；小视口自动堆叠）
mel-form-item--stack     强制hd/bd上下堆叠（兜底：JS容器检测自动追加，或业务手动）
mel-form-item--error     错误态（控件边框变红）
mel-form-ctrl            控件基类（input/select/textarea统一加此类）
mel-form-item__required  必填星号（位置由HTML书写顺序控制）
mel-form-item__tip       校验错误提示文字

可选增强脚本

mel-layout.js            可选增强脚本
  功能：检测 .mel-form-item--search 自身容器宽度，小于阈值自动追加 --stack
  阈值：默认 220px，可通过 window.MEL_LAYOUT_STACK_THRESHOLD 自定义
  兼容：现代浏览器用 ResizeObserver；IE9/IE10/IE11 降级为 resize + 节流轮询
  不引入：search 表单项回退到 CSS @media(max-width:768px) 视口响应式
