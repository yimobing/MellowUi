MelUi Dialog 弹窗插件

兼容：IE9/10/11、PC端、移动端自适应

一、引入方式

页面引入CSS样式与JS脚本，即可全局调用弹窗方法


<link rel="stylesheet" href="../src/components/dialog/style.css">
<script src="../src/components/dialog/index.js"></script>

二、全局调用方式

  • 快捷调用：MelUi.alert() / MelUi.confirm() / MelUi.prompt()
  • 完整自定义实例：new MelUi.Dialog(options)

三、全部配置参数说明

初始化传入配置对象，完整参数默认结构如下：


{
    title: "",
    content: "",
    theme: "info",
    showClose: false,
    btnDirection: "horizontal",
    btnFullWidth: false,
    buttons: null,
    defaultValue: "",
    onClick: null
}

title：弹窗标题，空字符串不渲染标题栏
content：弹窗正文提示文字
theme：按钮主题：info / success / warning / danger / default
showClose：是否显示右上角关闭按钮
btnDirection：按钮排布：horizontal横向、vertical竖向
btnFullWidth：按钮是否铺满整行宽度
buttons：自定义按钮数组，优先级高于默认按钮
defaultValue：prompt输入框默认填充文本
onClick：按钮点击回调函数

回调规则：默认双按钮弹窗 ret=1 取消，ret=2 确认；竖向不通栏时按钮自适应文字宽度居中
