    MelUi Core 核心能力

    Core 是 MelUi 的运行时底座，随主包加载，不单独打包成组件。对外提供 Loading / Spinner、Mask 遮罩和 Iframe 弹窗等顶层 API；zIndex、scrollLock、polyfill 由内部统一处理，不作为业务 API。

    一、Core 概览运行时能力、调用入口与手册分工

    Core 不是一个需要额外引入的“核心包”，它随 melui.js 一起加载。没有 melui.Core 对象，所有公开 API 都提升到 melui / MelUi 顶层。

    调用入口

    melui.openMask / closeMask / openIframe / closeIframe
    不存在 melui.Core；不要写成 melui.Core.showLoading()

    1.1 最小引入

    本页可以直接双击打开，但要让 F12 里的 melui 可用，需要先引入 MelUi 整包产物。CSS 在前，JS 在后：

    HTML
    <link rel="stylesheet" href="../release/dist/melui.min.css">
<script src="../release/dist/melui.min.js"></script>

    本页已经在 <head> / <body> 末尾实际引入这两个文件，打开后可直接在控制台执行 melui.openMask() 验证。业务页面按自己的目录调整路径，不要照抄 ../release/dist。

    只引主包：Core 的能力已经包含在 melui.min.js 里，不需要再单独引 Core；Util、Third 是独立产物，用到时再追加。

    路径提醒：上面的路径按完整工程的 demo/ 目录写；如果本地还没生成 release/dist 的 min 产物，先执行构建，或把路径改成你实际使用的 dist 产物。

    1.2 职责与边界

    Core 负责三件事：Loading 加载反馈、Mask 遮罩层、Iframe 内嵌弹窗。它解决的是“页面运行时”的公共问题，不负责按钮、表格、日期选择器这类界面组件。

    与组件的关系：Dialog、Drawer 等组件可以复用 Core 的遮罩、层级和滚动锁，但 Core 不反过来依赖任何组件。

    与 Util / Third 的关系：Core 不包含工具函数，也不内置 SheetJS、html2canvas；Util 看工具库手册，Third 看总入口的第三方适配章节。

    二、Mask 遮罩独立遮罩层，多层叠放、滚动锁与关闭回调

    Mask 是独立的遮罩层，不依附 Loading。它可以多层叠放，层级自增，滚动锁按引用计数管理；关闭时支持“后开先关”、全部关闭、指定 id 或节点。

    2.1 对外 API

    API 说明
    openMask(options) 打开遮罩，返回遮罩节点。同 id 已存在时直接返回已有节点，不重复创建。
    closeMask(target?) 不传参数关闭最后打开的一层；'all' 关闭全部；传 id 或节点关闭指定遮罩。

    2.2 默认参数

    参数 默认 说明
    id''留空自动生成 mel-mask-N。
    zIndex00 表示自动分配。
    color'rgba(0,0,0,0.4)'遮罩底色。
    opacity1透明度 0~1，叠加在底色之上。
    lockScrolltrue是否锁定页面滚动。
    clickClosefalse点击遮罩本身是否关闭自己。
    className''附加 class。
    onClosenull关闭回调，收到 { id, el }。

    2.3 行为约定

    • 同 id 复用：相同 id 的遮罩已经打开时，openMask 直接返回已有节点，不会重复创建。
    • 关闭顺序：closeMask() 关闭最后打开的一层；closeMask('all') 关闭全部；传 id 或节点关闭指定遮罩。
    • 滚动锁：按引用计数管理；同时打开多块遮罩时，只有最后一块关闭后才恢复页面滚动位置。
    • 移动端：遮罩会阻断 touchmove，避免 iOS / Android 页面跟着手指拖动。
    • 关闭回调：onClose 收到 { id, el }，可用于同步业务状态或清理挂件。

    2.4 示例

    JavaScript
    var mask = melui.openMask({
    id: 'edit-mask',
    clickClose: true,
    onClose: function (info) {
        console.log('遮罩关闭：' + info.id);
    }
});

// 关闭指定遮罩
melui.closeMask('edit-mask');

// 关闭全部
melui.closeMask('all');

    与 Loading 的关系：Loading 自带遮罩，但只服务于加载反馈；需要纯遮罩、点击关闭或自定义内容时，直接使用 Mask。

    三、Iframe 弹窗标题栏、按钮栏、遮罩与 iframe 内容

    openIframe 用于打开一个带标题栏、按钮栏、遮罩和 iframe 的弹窗。它适合嵌入独立页面，不是文档预览组件；MelUi 文档页面本身不使用 iframe 做导航。

    3.1 对外 API

    API 说明
    openIframe(options) url 必填；返回 { id, el, iframe, close }。缺少 url 时 warn 并返回 null。
    closeIframe(target?) 不传参数关闭最后一个；'all' 关闭全部；传 id 或节点关闭指定，返回 Boolean。

    3.2 常用参数

    参数 默认 说明
    url''iframe 地址，必填。
    caption''标题栏文字；为空且没有按钮时不显示信息栏。
    top'1%'距顶部距离，支持百分比或 px。
    width'98%'弹窗宽度，支持百分比或 px。
    titleHeight35标题栏高度，单位 px。
    titleFontSize''标题字号，可空。
    showCrosstrue是否显示右上 / 左上打叉。
    crossDirection'right'left / right。
    buttons[]按钮文字数组，例如 ['取消', '确定']。
    btnTheme''按钮主题，空或 back。
    btnBgColor[]与 buttons 对应的背景色数组。
    btnDirection'horizontal'horizontal / vertical。
    btnClickClosefalsetrue 时点按钮先关闭当前 iframe，再执行回调。
    btnCallBacknull按钮回调；ret 从 1 开始，this 是合并后的 options。
    element''挂载节点，默认 body。
    position'fixed'fixed 默认全屏居中；relative 挂到指定 element。
    masktrue是否显示遮罩。
    openCallBacknull打开完成回调，this 是合并后的 options。
    closeCallBacknull关闭回调，收到 { id, el }。

    3.3 params 高级参数

    params 字段 默认 说明
    frameId''iframe DOM id；留空自动生成。
    frameName'mel-frame-name'iframe name。
    frameZindex0弹窗层级；0 自动分配。
    frameRadiustrue是否使用圆角。
    frameBordertrue是否显示边框。
    maskId''遮罩 id；留空自动生成。
    maskZindex0遮罩层级；0 自动分配。
    animation{ enable: true, direction: 'top' }打开动画配置。

    3.4 按钮回调与关闭

    • ret 从 1 开始：btnCallBack(ret) 的 ret 从 1 开始，1 表示第 1 个按钮，2 表示第 2 个按钮。
    • this 指向：回调里的 this 是合并后的 options，可以直接调用 this.close() 关闭当前窗口。
    • 先关后回调：btnClickClose: true 时，点按钮先关闭当前 iframe，再执行 btnCallBack。
    • 关闭全部：closeIframe() 关闭最后一个；closeIframe('all') 关闭全部；传 id 或节点关闭指定。

    HTTPS / HTTP：当前页面是 HTTPS、目标地址是 HTTP 时，openIframe 会提示“目标链接为 HTTP 协议，当前页面为 HTTPS 协议，无法直接嵌入”，并返回 null。这是浏览器的混合内容策略，不是 MelUi 能绕过的。

    目标站点限制：目标页面设置了 X-Frame-Options 或 CSP frame-ancestors 时，iframe 会被浏览器拦截，MelUi 无法绕过。

    3.5 示例

    JavaScript
    var frame = melui.openIframe({
    url: 'https://example.com/detail',
    caption: '订单详情',
    width: '90%',
    top: '5%',
    buttons: ['取消', '确定'],
    btnCallBack: function (ret) {
        if (ret === 2) {
            // this 是合并后的 options
            this.close();
        }
    }
});

// 关闭最后打开的 iframe
melui.closeIframe();

    四、运行时约定zIndex、滚动锁与 polyfill，仅供理解，不作为业务 API

    4.1 zIndex 层级

    Core 维护一个全局自增层级，起点 2000，每次加 10；遮罩、Loading、iframe 自动分配层级，避免互相压盖。一般不需要手动传 zIndex，除非要接管外部弹层的层级。

    4.2 scrollLock 滚动锁

    滚动锁采用 html / body 双锁、滚动条宽度补偿和滚动位置还原，按引用计数管理。Loading 与 Mask 同时打开时，不会因为先关一个就提前解锁。

    4.3 polyfill

    polyfill 在 core.js 最先执行，补 bind、filter、indexOf、forEach、Array.from、getElementsByClassName、matches、closest、classList。它不生成 melui.polyfill 对象。

    使用建议：业务代码只依赖公开 API；zIndex、scrollLock、polyfill 属于内部实现，不建议在业务里直接调用或改写。

    Loading：Loading 的 API、默认参数和示例请直接看 Core Loading 转圈加载使用手册。

    五、常见问题遮罩关闭顺序、iframe 空白与多层叠放

    5.1 遮罩关闭顺序不对

    closeMask() 不传参数关闭最后打开的一层；传 'all' 关闭全部；传 id 或节点关闭指定遮罩。多层叠放时不要用“关一个”去清理全部。

    5.2 iframe 打开空白或直接失败

    先看协议：当前页面是 HTTPS、目标地址是 HTTP 时会被混合内容策略拦截。其次检查目标站点是否设置了 X-Frame-Options 或 CSP frame-ancestors，这类限制 MelUi 无法绕过。

    5.3 遮罩与 Loading 一起打开

    两者都使用 Core 的滚动锁，按引用计数叠加。分别关闭，等最后一个遮罩或 Loading 关闭后，页面滚动才会恢复。
