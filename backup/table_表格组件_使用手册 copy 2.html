1. 功能概览

MelUi Table 是一个数据驱动的原生表格控件（录入/展示双用），兼容 IE9 / IE10 / IE11 / Edge，无第三方依赖。核心层只留骨架，扩展能力（序号、勾选、排序、分页、合计、合并表头、展开行、导出等）全部做成插件的形式，可按需启用。

核心特点

IE9+ 全兼容 纯原生 JS，不依赖 jQuery / 框架；不用 let / const / 箭头函数 / 模板字符串，可直接跑在老内网环境。
数据驱动，DOM 只是投影 数据统一存在 DataStore，读取、保存、导出都走数据层，不从 DOM 反查 input 的值。
原生 table-layout:fixed 列宽由浏览器原生表格布局计算，避免 JS 反复测量 DOM 造成重排重绘。
插件化分层 核心层只保留骨架，序号、状态列、勾选、排序、分页、合计、合并表头、展开行、导出按需启用。
录入 / 展示双用 同一套组件既能做纯文本展示表，也能做大量 input / radio / checkbox 的录入表。
完整销毁机制 destroy() 清理 resize / scroll 监听、恢复 body 样式、销毁插件，避免内存泄漏。

能做什么

  1. 配置 columns 渲染列：标题、副标题、字段、列宽、对齐、输入控件、格式化。
  2. 录入能力：只读 readonly、禁用 disabled、默认值 defaultValue、必填 required、唯一值 unique、列级自定义校验 validator、数字过滤 type、小数位 digit、formatter 显示格式化。
  3. 增删改查：新增行（自动滚动定位 + 自动聚焦输入框）、删除行、清空、整表替换。
  4. 外观：边框 bordered、斑马纹 stripe、行悬浮高亮 hoverHighlight、行高 rowHeight、表头高度 headerHeight。
  5. 布局：左侧冻结列 fixedLeftColumns、列宽弹性铺满 fitWidth、视口高度自适应 fitViewport、表头固定。
  6. 表格上下额外区块 extraBefore / extraAfter，用于多表格 / 多切片场景在上方放查询条件、标题说明。
  7. 列级控制：sortable 控制该列能否点击排序、visible 控制该列显示与隐藏（DOM 保留、可运行时切换）。
  8. 插件：序号、勾选、状态列、排序、分页（本地 / 远程 / 兜底降级）、合计行、合并表头、展开行、导出（xlsx / xls / csv），详见 3.3 插件基础 与 3.4 插件详解。
  9. 事件：点击、编辑、勾选、排序、翻页、展开、渲染完成，详见 3.5 事件总线。

2. 快速开始

这一节只做一件事：让你在 3 分钟内把表格跑起来。示例可直接复制成一个 html 文件打开。

最小可运行示例

新建一个 html 文件，把下面整段粘进去，用浏览器打开即可看到表格。

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <link rel="stylesheet" href="./table/index.css">
    <script src="./table/index.js"></script>
    <script src="./table/core/data-store.js"></script>
    <script src="./table/core/event-bus.js"></script>
    <script src="./table/core/renderer.js"></script>
    <script src="./table/core/table.js"></script>
    <script src="./table/plugins/plugin-base.js"></script>
    <script src="./table/plugins/serial-no.js"></script>
</head>
<body>
<div id="table-box"></div>

<script>
    var columns = [
        {field: "name",  title: "名称", width: 160, renderer: "input", required: true,  align: "left"},
        {field: "price", title: "单价", subtitle: "(元)", width: 120, renderer: "input",
         type: "float", digit: 2, align: "right"}
    ];

    var data = [
        {name: "测试项A", price: 100.00},
        {name: "测试项B", price: 200.50}
    ];

    var table = MelUi.Table({
        el: "#table-box",   // 挂载节点，必填
        columns: columns,   // 列配置，必填
        data: data,         // 行数据，必填
        rowHeight: 40,
        bordered: true,
        stripe: true,
        plugins: ["SerialNo"]   // 插件按需启用
    });
</script>
</body>
</html>
data 与 columns 的关系： data 是行数据数组，每个元素是一行的数据对象； 对象里的 key 与 columns 里每一项的 field 对应。 上例第一列读每行的 name，第二列读 price。 某行缺字段时按该列 defaultValue 补值（未配置则显示空）。

发布版引入

打包发布后只需要一个 js + 一个 css，不用按模块逐个引入：

<link rel="stylesheet" href="./dist/table.min.css">
<script src="./dist/table.min.js"></script>

<!-- 或者整包 -->
<link rel="stylesheet" href="./dist/melui.min.css">
<script src="./dist/melui.min.js"></script>

本地开发版引入顺序

未打包时按「渲染器 → 核心 → 插件」的顺序引入，入口 index.js 负责把各模块挂到 MelUi.Table 命名空间。

<!-- 入口 -->
<link rel="stylesheet" href="./table/index.css">
<script src="./table/index.js"></script>

<!-- 单元格渲染器 -->
<script src="./table/cell-renderers/text.js"></script>
<script src="./table/cell-renderers/input.js"></script>
<script src="./table/cell-renderers/textarea.js"></script>
<script src="./table/cell-renderers/radio.js"></script>
<script src="./table/cell-renderers/checkbox-cell.js"></script>
<script src="./table/cell-renderers/button.js"></script>

<!-- 核心 -->
<script src="./table/core/data-store.js"></script>
<script src="./table/core/event-bus.js"></script>
<script src="./table/core/renderer.js"></script>
<script src="./table/core/layout.js"></script>
<script src="./table/core/table.js"></script>

<!-- 插件（按需引入，不用就不要引） -->
<script src="./table/plugins/plugin-base.js"></script>
<script src="./table/plugins/serial-no.js"></script>
<script src="./table/plugins/checkbox.js"></script>
<script src="./table/plugins/state-column.js"></script>
<script src="./table/plugins/sort.js"></script>
<script src="./table/plugins/pagination.js"></script>
<script src="./table/plugins/summary.js"></script>
<script src="./table/plugins/header-merge.js"></script>
<script src="./table/plugins/row-expand.js"></script>
<script src="./table/plugins/export.js"></script>
初始化两种写法等价： MelUi.Table(options) 是工厂写法（推荐）， new MelUi.Table.Core(options) 是直接 new 构造函数，两者行为一致。

3. 配置项 options

初始化时传给 MelUi.Table({...}) 的对象就是 options。它由四部分组成：基础配置（3.1）、列配置 columns（3.2）、插件 plugins（3.3 / 3.4）、事件 events（3.5）。

必填 必须传入； 可选 未传时取默认值； 进阶 复杂场景才用，新手可先跳过； 参数名带下划线的可点击跳到对应章节。

3.1 基础配置

直接写在 options 根层级的参数：挂载节点、数据、外观、布局尺寸、分页模式、上下额外区块、展开行渲染函数。

必填三项

参数类型默认值说明
elString / HTMLElement—必填 表格挂载节点，传 CSS 选择器字符串或 DOM 元素。
columnsArray[]必填 列配置数组，详见 3.2 列配置项 columns。
dataArray[]必填 表格数据，对象数组，每个对象对应一行。

外观

参数类型默认值说明
borderedBooleantrue是否显示单元格边框。
stripeBooleanfalse是否隔行变色（斑马纹）。
hoverHighlightBooleantrue鼠标悬停行是否高亮。
showSelectAllBooleantrue勾选列表头是否显示全选复选框（配合 Checkbox 插件）。
rowHeightNumber40行高，单位 px。
headerHeightNumber / 'auto''auto'表头高度。'auto' 由内容自动撑开（合并表头会自然变高）；传数值时使用固定高度（px）。

布局与尺寸

参数类型默认值说明
fixedLeftColumnsNumber0左侧连续冻结列数量，0 = 不冻结，1 = 冻结第 1 列。
注意：插件会自动插入虚拟列，冻结数量要把它们算进去（顺序为展开箭头列 → 勾选列 → 序号列 → 业务列）。
fitViewportBooleantrue进阶 是否垂直适配视口。true 时 bodyHeight、el 自定义高度失效，表格自动占满页面剩余高度，页面不出现垂直滚动条。
同一页面最多一个表格开启 fitViewport，多个表格请关闭。
viewportBottomGapNumber16仅 fitViewport=true 生效。表格与视口底边预留的间隙（px），露出 body 背景色。
bodyHeightNumber0表身固定高度（px）。0 = 不限制，由 el 节点控制。fitViewport=true 时本参数无效；fitViewport=false 且 >0 时会把 el 高度强制为 auto!important。
fitWidthBooleanfalse进阶 false = 固定列宽模式，用 columns 的 width(px)；true = 弹性模式，列宽总和小于容器时按 width 权重拉伸铺满，大于容器时不拉伸并出现横向滚动条。

分页

参数类型默认值说明
remotePagingBooleanfalse进阶 是否后端远程分页。
false：前端本地分页，一次性传全部 data，组件内部切片；
true：后端远程分页，翻页 / 改每页条数时触发 pageChange，业务请求后端后用 setData 回填。
totalNumber0总记录数，仅 remotePaging=true 生效，由外部传入后端总条数，组件据此渲染分页栏。
enableRemotePagingFallbackBooleantrue进阶 是否兜底后端远程分页，仅 remotePaging=true 生效。后端 total=0 或小于当前列表条数时：true 则自动降级为前端本地分页；false 则严格信任后端 total。
标准分页接口建议 false；接口不返回总记录数时设 true。
addRowModeString'currentPage'新增行插入位置，仅 remotePaging=false 有效。
'currentPage'：插入当前页数据集合，配合 addRow 的 position 控制当前页首 / 尾；
'global'：插入全局原始数据数组首 / 尾。
remotePaging=true 时本参数无效（按全局处理）。

表格上下额外区块（extraBefore / extraAfter）

多表格 / 多切片场景常用：在表格上方放查询条件、单据标题，下方放补充说明。区块与表头、表身同处 .mel-table-container 内，宽度自动与表头对齐。

参数类型默认值说明
extraBeforeString / Function''表格上方额外内容。
String：直接作为 HTML 渲染；
Function：以表格实例为参数，返回 HTML 字符串；
取值或返回值为空则不渲染该区块。
extraAfterString / Function''表格下方额外内容，用法同 extraBefore。
var table = MelUi.Table({
    el: '#table-box',
    columns: columns,
    data: data,
    extraBefore: '<div class="query-bar">行情单号：XJ2026001</div>',
    extraAfter: function(tb) {
        return '<div class="foot-tip">共 ' + tb.getData().length + ' 条记录</div>';
    }
});
说明：两个区块不参与列对齐、固定列、排序、勾选、合并表头等任何表格逻辑，区块里的按钮需业务自己绑定事件； fitViewport=true 时，组件计算表身高度会把这些区块（含 margin）一起扣掉，不会溢出屏幕。

展开行渲染函数 expandRender

启用RowExpand 展开行插件后，可双击表格某行展开显示当前行数据，并使用此参数来自定义展开区域内容。

参数类型默认值说明
expandRenderFunction未配置进阶 配合 RowExpand 展开行插件 使用，自定义展开区域内容。
说明：本参数未配置或返回值为空 / 纯空白 / null / undefined：使用插件内置默认面板（一行一个字段，左列名浅色、右值深色）。
使用本参数需返回：HTML 字符串。
回调参数 function(rowData, columnList)：
· rowData：本行业务字段副本（不含 _ 开头的内部字段）
· columnList：可见业务列信息数组 [{title, field, value, rawValue}]
  title = 表头显示名称；field = 字段名；
  value = 该列 formatter 格式化后的展示值（与单元格同口径，radio 的 1/0 会变成「是/否」）；
  rawValue = 原始业务值（未格式化，供逻辑判断）
expandRender: function(rowData, columnList) {
    var html = '<div class="my-detail">';
    for (var i = 0; i < columnList.length; i++) {
        html += '<p>' + columnList[i].title + '：' + columnList[i].value + '</p>';
    }
    html += '</div>';
    return html;
}

3.2 列配置项 columns

columns 是 options 里描述「有哪些列、每列怎么显示、怎么编辑」的数组，每一项对应一列。它只是 options 中的一项配置，不是全部。
字段类型默认值说明
fieldString—必填 字段名，数据读写唯一标识，必须与 data 对象中的 key 对应。
内部列以 _ 开头（_serialNo / _checkbox / _state / _expand），不要手写。
titleString—必填 列标题，显示在表头。合并表头的分组节点只写 title，不写 field。
subtitleString''列副标题，显示在标题下方的小字，如 "(元)"、"(㎡)"。
widthNumber—列宽（px）。table-layout:fixed 模式下由该值决定列宽。
alignString'left'单元格水平对齐：'left' / 'center' / 'right'。
rendererString'text'单元格渲染器名称，详见 单元格渲染器 renderer。
readonlyBooleanfalse整列只读。input / textarea / radio 渲染时加 readonly，不可编辑。
disabledBooleanfalse整列禁用。input / textarea / radio / button 渲染时加 disabled。
defaultValueAny—新增行时该列的默认值。行数据中该字段为 undefined 时自动填入。
requiredBooleanfalse必填标记。input / textarea 生成「请输入xxx」placeholder；validate() 校验该列不能为空。
uniqueBooleanfalse唯一值标记。validateUnique() 校验该列整表不重复。
validatorFunction—列级自定义校验钩子 function(value, rowData, rowIndex){ return 提示文本 }，由 validate() 调用。
返回非空字符串 = 不通过，返回 '' / undefined = 通过；提示文本原样并入返回结果，格式为 第N行【某一列的列标题】不能为空。
与 required 同时配置时：必填判空失败会直接跳过 validator，不会对同一格提示两次。
未配置 required、也没配 validator 的列不参与校验。
请注意：只有调用 validate() 函数，本参数配置才会起生效。
sortableBooleantrue该列是否参与表头点击排序（需启用 Sort 插件）。
true / 不写：表头显示手型光标（cursor:pointer），点击切换升序降序；
false：表头是普通光标，点击不排序。
没有 field 的分组表头、_ 开头的内部列恒不可排序。
visibleBooleantrue该列是否显示。false 只是「界面上不显示」，不是「不创建」：列配置、列数据、formatter 全部保留，表头 / 表身 DOM 照常渲染（F12 能看到），只是用零宽占位（width:0 / padding:0 / border:0 / visibility:hidden）不占可见宽度，后续列宽不会被挤乱。
与「columns 里干脆不配这一列」有本质区别：那种做法数据、导出、切回显示全都会丢。运行时切换用 setColumnVisible(field, visible)。
隐藏列默认不参与导出，需要带出用 Export 的 includeHiddenColumns:true。
typeString—数据类型过滤：'int'（只允许整数和负号）/ 'float'（数字、小数点、负号）。输入时实时过滤非法字符。不填则不过滤。
digitNumber—小数位数。input 渲染时按该值 toFixed 显示，如 2 = 两位小数。配合 type:'float'。
formatterFunction—显示格式化函数 function(value, rowData){ return 显示文本 }。只影响显示与导出，不改原始数据。text / radio 渲染器会调用；expandRender 的 columnList.value 也走它。
radioOptionsObject{yes:'1', no:'0'}radio 渲染器专用：两个选项的值。显示文字用 formatter 定制。
buttonTextString'按钮'button 渲染器专用：按钮文字。
buttonIconString''button 渲染器专用：Font Awesome 图标名，渲染为 <i class="fa fa-图标名">。
childrenArray—仅 HeaderMerge 合并表头使用：子列数组。分组节点只写 title + children。
// 列级开关示例
var columns = [
    {field: "code",  title: "编号", width: 100},                              // 默认可排序、显示
    {field: "dist",  title: "省市区", width: 220, visible: false},             // 隐藏列：DOM 保留，可再显示
    {field: "price", title: "楼盘均价", width: 120, sortable: false},          // 该列表头不可点击排序
    {field: "amount", title: "总金额", width: 120, align: "right", required: true,
     validator: function(value, rowData, rowIndex) {
         // 返回空字符串 = 通过；返回文本 = 不通过，文本会拼进 validate() 的提示里
         if (parseFloat(value || 0) < 0) return "不能小于 0";
         return "";
     }}
];

// 校验：必填 + validator 一起返回
var err = table.validate('all');   // 形如 "第3行【总金额】不能小于 0\n"
插件会往 columns 里插内部列： SerialNo 插 _serialNo， Checkbox 插 _checkbox， StateColumn 插 _state， RowExpand 插 _expand（固定最左）。 启用后冻结列数量要把这些列算进去。

单元格渲染器 renderer

渲染器把「值 + 列配置 + 行数据」变成一个单元格的 HTML。内置 6 种，全部注册在 MelUi.Table.cellRenderers 上。

renderer 值渲染结果说明与相关列配置
'text'纯文本 <span>默认渲染器。支持 formatter 格式化显示，空值显示为空。
'input'单行输入框支持 readonly / disabled / required(placeholder) / digit / type(输入过滤)。
'textarea'多行文本域支持 readonly / disabled / required(placeholder)。
'radio'是 / 否单选按钮组用 radioOptions 指定两个值；显示文字用 formatter 定制；支持 readonly / disabled。
'checkbox'勾选框（多选 / 单选）主要给 Checkbox 插件的选择列用；Checkbox 插件 mode:'single' 时渲染成 radio，否则 checkbox。
'button'操作按钮buttonText 设置文字、buttonIcon 设置图标；支持 disabled。

自定义渲染器：往 MelUi.Table.cellRenderers 注册一个函数，签名 function(value, column, rowData)，返回 HTML 字符串，然后在列的 renderer 里填这个名字。

// 注册自定义渲染器：金额显示为红色，保留两位小数
MelUi.Table.cellRenderers.money = function(value, column, rowData) {
    var num = parseFloat(value);
    var text = isNaN(num) ? '' : num.toFixed(column.digit || 2);
    return '<span style="color:#c0392b;">' + text + '</span>';
};

// 列配置里使用
var columns = [
    {field: "amount", title: "金额", width: 120, renderer: "money", digit: 2, align: "right"}
];
注意：渲染器返回的 HTML 会被直接写进单元格，业务数据来自用户输入时请先转义，避免 XSS。

3.3 插件基础

插件是 options 里 plugins 这一项配置。本节只讲两件事：怎么注册插件、有哪些内置插件；每个插件的参数与用法见 3.4 插件详解。

注册插件（启用插件）

核心层只负责数据、渲染、事件，扩展能力全部通过 plugins 数组注册。三种写法完全等价，可混用：

// 写法一：字符串简写 —— 只写插件名，使用默认配置
plugins: ['SerialNo', 'StateColumn']

// 写法二：对象简写 —— name 指定插件名，其余属性作为该插件配置
plugins: [
    {name: 'SerialNo', width: 60},
    {name: 'Pagination', pageSize: 20}
]

// 写法三：数组简写 —— 第一项插件名，第二项配置对象
plugins: [
    ['RowExpand', {expandSingle: false, expandColWidth: 40}],
    ['HeaderMerge', {borderPatch: true}]
]

// 三种混用也完全没问题
plugins: [
    'Checkbox',
    {name: 'Pagination', pageSize: 20},
    ['RowExpand', {expandSingle: false}]
]
要点：
① 插件名就是 MelUi.Table.plugins[插件名] 的键，如 'SerialNo' 对应 MelUi.Table.plugins.SerialNo；
② 插件按数组顺序初始化，SerialNo / Checkbox / StateColumn 会往 columns 里插列，先后会影响列顺序；
③ 例外：RowExpand 的箭头列无论插件排第几，都会被归位到最左；
④ 插件 js 没引入时不会报错，只是不生效 —— 排查「插件没反应」先确认 js 是否引入了。

内置插件一览

插件名作用说明
Layout布局增强未完成 暂未开发完成，启用不生效；基础布局由渲染器内置提供
SerialNo序号列按当前页可见行计算序号；后端远程分页跨页连续
Checkbox多选 / 单选列配合 getSelectedData / selectAll 等 API
StateColumn行状态列新增 / 修改 / 已保存；配合 getDirtyData / markSaved
Sort表头点击排序修改数据源顺序；支持仅当前页排序
Pagination分页栏本地 / 后端远程分页；支持兜底降级
Summary合计行对指定字段求和，值变化自动重算
HeaderMerge合并表头二级、三级…合并，建议最多三级
RowExpand展开行（详情面板）点箭头在该行下方插入一条跨列详情行；不是树形表格

3.4 插件详解

每个插件固定结构：一句话作用 → 参数表 → 启用写法 → 配套 API / 事件。参数表统一为「参数 | 类型 | 默认值 | 说明」，方便直接查。

Layout · 布局增强插件 暂未完成

作用：规划中的高阶布局能力（左右双侧固定列、列宽拖拽、弹性自适应列宽、复杂 resize 重排）。当前启用不生效。

参数类型默认值说明
———暂无参数。启用与否都不影响表格，基础布局请直接用 3.1 基础配置 里的 fixedLeftColumns / fitWidth / fitViewport。
// 当前状态：启用无效，不建议配置
plugins: ['Layout']

// 基础布局由渲染器内置实现，不需要插件：

作用：在表格最前面插入一列序号。增删行、翻页后自动重排；后端远程分页时按「页码 + 页容量」计算，跨页连续。

// 单选

// 配套 API（详见 4.2 实例方法）

参数类型默认值说明

plugins: [['StateColumn', {

Sort · 表头排序

作用：点击表头切换升序 / 降序。只修改数据源顺序，不重建表头；无 field 的分组表头不参与排序。

列级开关：某列不想被点，就在列配置里写 sortable:false。 可排序的表头由渲染器打上 mel-th-sortable 类，光标是手型（cursor:pointer）； sortable:false 的列是普通光标，点击没有任何反应，不派发 sortChange。 不写该项视为可排序。只在启用 Sort 插件后才会出现手型光标，没装 Sort 的表头永远是普通光标。
参数类型默认值说明
defaultFieldString''初始化时默认排序列的字段名，空表示不默认排序。
defaultOrderString'asc'默认排序方向：'asc' 升序 / 'desc' 降序。
sortCurrentPageOnlyBooleantrue是否只对当前页排序，仅 remotePaging=false 时有效（remotePaging=true 强制全量排序）。
true：只排当前页切片区间并回填该区间，其它页顺序不变，数据不会跑到其它页；
false：对整个数据源排序后重新分页切片。
plugins: [['Sort', {defaultField: 'scjj', defaultOrder: 'desc', sortCurrentPageOnly: true}]]

// 排序事件（事件名是 sortChange，不是 sort）
table.on('sortChange', function(data) {
    // data = {field: 排序字段, order: 'asc' | 'desc'}
});

Pagination · 分页

作用：底部分页栏，支持数字列表 / 下拉两种模式，支持前端本地分页、后端远程分页，以及后端 total 异常时的兜底降级。

参数类型默认值说明
pageSizeNumber10每页条数。
pageModeString'list''list'：数字页码按钮；'select'：页码下拉选择。
pageListSizeNumber5数字列表模式显示几个页码按钮。
positionString'bottom''bottom' 表格下方 / 'top' 表格上方 / 'fixed' 固定页面底部。
alignString'right'分页内容对齐：'left' / 'center' / 'right'。
showQuickJumperBooleantrue是否显示「跳至 __ 页」快速跳转。
showSizeChangerBooleantrue是否显示「每页 __ 条」切换。候选：5 / 10 / 15 / 20 / 30 / 40 / 50 / 60 / 70 / 80 / 100 / 150 / 200 / 300 / 400 / 500 / 1000 / 2000 / 5000；当前 pageSize 不在候选内时自动追加并选中。
plugins: [['Pagination', {
    pageSize: 20,
    pageMode: 'list',
    pageListSize: 5,
    position: 'bottom',
    align: 'right',
    showQuickJumper: true,
    showSizeChanger: true
}]]

后端远程分页（标准接口）：关闭兜底，严格信任后端 total。

var table = MelUi.Table({
    el: '#table-box',
    columns: columns,
    data: [],
    remotePaging: true, // true 后端远程分页
    total: 100, // total等于当前列表条数
    enableRemotePagingFallback: false, // false 关闭兜底，严格信任后端 total
    plugins: [['Pagination', {pageSize: 20}]],
    events: {
        onPageChange: function(data) {
            // data = {curpage: 当前页, pagesize: 每页条数}
            if (table.options.remotePaging == false) return; // 仅开启后端远程分页(remotePaging = true)才请求后端数据
            if (table.isFallbackPaging) return; // 兜底降级中：内部已对当前数据做本地分页，切勿再请求后端覆盖数据
            // 后端total本来就正常，请求后端
            requestList(data.curpage, data.pagesize, function(res) {
                table.setData(res.list);   // 用 setData 回填当页数据
            });
        }
    }
});

后端远程分页（接口不返回总记录数，或返回的总记录数小于当前列表条数）：开启兜底，组件自动用当前这批数据做前端分页。

var table2 = MelUi.Table({
    el: '#table-box2',
    columns: columns,
    data: allData,
    remotePaging: true, // true 后端远程分页
    total: 0, // total=0 或小于当前列表条数时
    enableRemotePagingFallback: true, // true 开启兜底：组件用当前数据做前端本地分页，分页栏按实际条数显示，不再按 pageSize 切
    plugins: [['Pagination', {pageSize: 20}]],
    events: {
        onPageChange: function(data) {
            // data = {curpage: 当前页, pagesize: 每页条数}
            if (table2.options.remotePaging == false) return; // 仅开启后端远程分页(remotePaging = true)才请求后端数据
            if (table2.isFallbackPaging) return; // 兜底降级中：内部已对当前数据做本地分页，切勿再请求后端覆盖数据
            // 后端 total 恢复正常后才请求后端
            requestList(data.curpage, data.pagesize, function(res) {
                table2.setData(res.list);  // 用 setData 回填当页数据
            });
        }
    }
});

Summary · 合计行

作用：在表身底部渲染一行合计，对指定字段求和；单元格值变化时自动重算。

参数类型默认值说明
columnsArray[]需要合计的字段名数组，如 ['mj', 'scjj', 'zje']。
titleString'合计'合计行标题文字。
titleColumnNumber0标题放在第几列（列索引，从 0 开始）。
scopeStringcurrentPage合计统计范围。`currentPage`：仅统计当前分页(比如第2页)的数据；`all`：统计所有分页(第1,2,3...最后一页)的全部数据。远程分页设置`all`时，组件不会自动计算，需要配置 externalData。
具体解释：
'currentPage' —— 无论本地分页还是远程分页，只统计当前页可见行（含本页新增草稿行）
'all' —— 统计全部数据：
本地分页：前端对全量数据源自动聚合；
远程分页：前端拿不到全量数据，不自动计算，只渲染 externalData，未配置则显示 "—"
externalDataObject{}后端远程分页、且 scope="all" 时后端传入的全局合计对象，字段和 columns 保持一致；scope=currentPage 时本参数无效（完全不读`externalData`，传了也不生效）。
eg.externalData: { mj: 100, scjj: 200, zje: 300 } 
plugins: [['Summary', {columns: ['mj', 'scjj', 'zje'], title: '合计', titleColumn: 2, scope: 'currentPage', externalData: {}}]]
说明：启用分端远程分页时，如果要想统计当前表格所有分页的某些字段的汇总数据，则后端：必须返回汇总数据，否则前端无法知道所有页的全部汇总数据。前端：必须设置 scope = 'all'，且 externalData 必须传值，不能是空对象。 

        eg. 以下数据表示当前表格（假设10页）10页汇总起来的面积、市场价值、总金额
        externalData {
            mj: 100, // 面积
            scjj: 200, // 市场价值
            zje: 300 // 总金额
        }

HeaderMerge · 合并表头

作用：对表头做二级、三级、四级…合并（层级由 columns 的 children 决定），建议最多到三级。

参数类型默认值说明
groupHeaderClassString''分组表头（父级 th）追加的样式类。
leafHeaderClassString''叶子表头追加的样式类。
borderPatchBooleantrueIE9 合并边框修复开关。
plugins: [['HeaderMerge', {
    groupHeaderClass: '',
    leafHeaderClass: '',
    borderPatch: true
}]]

columns 改造方式：把要合并的列放进一个 title + children 的分组节点，叶子列配置项完全不变。

// 改造前：单行平铺
columns: [
    {field: 'xh_self', title: '编号',   width: 100, renderer: 'text',  align: 'center'},
    {field: 'mj',      title: '面积',   subtitle: '(㎡)', width: 100, renderer: 'input', type: 'float', digit: 2, align: 'center'},
    {field: 'area',    title: '省市区', width: 200, renderer: 'input', readonly: true, align: 'left'}
]

// 改造后：这三列放进一个 children，父级只写 title
columns: [
    {
        title: '基础信息',
        children: [
            {field: 'xh_self', title: '编号',   width: 100, renderer: 'text',  align: 'center'},
            {field: 'mj',      title: '面积',   subtitle: '(㎡)', width: 100, renderer: 'input', type: 'float', digit: 2, align: 'center'},
            {field: 'area',    title: '省市区', width: 200, renderer: 'input', readonly: true, align: 'left'}
        ]
    },
    {field: 'price', title: '均价', width: 100},
    {field: 'memo',  title: '备注', width: 140}
];
要点：
① 分组节点只写 title + children，不要再写 field；
② 叶子列的 field / width / renderer 原样保留；
③ 复选框列、序号列、展开箭头列由插件自动插入，合并表头会把它们一起算进表头网格（冻结列、滚动同步都按网格取 th）；
④ 合并后每一行的逻辑最后一列 th 会带 mel-th-merge-lastcol 类，用来补回被 th:last-child{border-right:0} 抹掉的右边框；单级表头不受影响。

RowExpand · 展开行

作用：点击行首箭头，在该行下方插入一条跨全部列的详情行，用来展示本行详情。注意：这是行详情展开，不是树形表格 —— 展开区域不是业务数据行，也不能再嵌套展开。

参数类型默认值说明
expandSingleBooleanfalse是否手风琴模式。
false：允许多行同时展开；
true：同一时间只能展开一行（展开新行自动收起旧行）。
expandColWidthNumber40展开箭头列宽度（px）。
plugins: [['RowExpand', {expandSingle: false, expandColWidth: 40}]]

行为说明：

  • 箭头列自动插在最左，是虚拟列 _expand，不需要你写进 columns。最终顺序：展开箭头列 → 勾选列 → 序号列 → 业务列。
  • 点箭头只做展开 / 收起，不会触发 rowClick（避免业务「点整行弹详情」被箭头误触发）。
  • 展开区域内容：未配置 expandRender → 内置默认面板（一行一个字段，左列名浅色、右值深色）；配置了且返回值 trim 后非空 → 用你返回的 HTML；返回空白 → 回退内置默认面板。
  • 默认面板和自定义渲染共用同一套列信息，value 已过该列 formatter（radio 的 1/0 会显示成「是/否」），内部虚拟列自动跳过。
  • 展开状态记在行对象上：翻页、排序后仍跟随该行；行被删除或 setData 换数据后自然失效。
  • 展开区域内部是纯业务 HTML，不参与编辑 / 勾选 / 排序。

配套事件：expandChange，参数 {rowId, rowData, expanded}，状态切换完成后触发（详见 事件列表）。

// 常见用途：展开时才去请求这一行详情（懒加载）
table.on('expandChange', function(data) {
    if (!data.expanded) return;
    requestDetail(data.rowData.id, function(res) {
        // 展开区域 DOM 由 expandRender 输出，插件不代理填充，业务自己渲染
        document.getElementById('detail-' + data.rowId).innerHTML = res.html;
    });
});

Export · 导出文件

作用：读取数据源直接导出文件，不遍历 DOM；导出时会应用列的 formatter。支持 .xlsx（真 Excel 2007+）、.xls（HTML 伪装，兼容 IE9）与 .csv（纯文本）。

参数类型默认值说明
formatString'xlsx'导出格式：
'xlsx'：真 Excel 2007+ 文件（ZIP + OOXML），表头加粗、按列宽排布、冻结首行，Excel 打开无格式警告；
'xls'：HTML 伪装的 Excel，兼容 IE9，Excel 打开可能提示「格式与扩展名不一致」；
'csv'：纯文本，逗号/制表符分隔，见 csvDelimiter。
老 IE 降级：IE9（无 Blob）、IE10（Blob 不支持二进制片段）导出 xlsx / csv 时会弹确认框，点确认自动降级导出 .xls，点取消不导出。
filenameString'导出数据'导出文件名（不含扩展名），扩展名由 format 决定。
csvDelimiterString'\t'仅 format:'csv' 生效，单元格分隔符。
'\t'（默认，制表符）：Excel 双击打开就是正常的一列列单元格，中文不乱码；
','（逗号）：给后端程序消费（如导入数据库）时用，Excel 里整行显示为一条，便于按纯文本行解析。
CSV 内部固定 UTF-16LE 编码（文件头 FF FE），后端读取时按 UTF-16 解析。
includeHiddenColumnsBooleanfalse是否导出隐藏列，即列配置 visible:false 的列。默认不导出。
includeInnerColumnsBooleanfalse是否导出内部列，即 field 以 _ 开头的序号 / 状态 / 选择 / 展开列。默认不导出。
与 includeHiddenColumns 互不相关：一个管「内部列」，一个管「业务隐藏列」，需要时各开各的。
// 默认导出真 xlsx（推荐，中文与样式都稳）
plugins: [['Export', {filename: '楼盘数据'}]]

// 逗号 CSV，给后端导入用
plugins: [['Export', {filename: '楼盘数据', format: 'csv', csvDelimiter: ','}]]

// 导出时把隐藏列、内部列一起带出去
plugins: [['Export', {filename: '楼盘数据', format: 'xlsx', includeHiddenColumns: true, includeInnerColumns: true}]]

// 触发导出：先拿到 Export 插件实例再调用 export()
function exportData() {
    for (var i = 0; i < table._pluginInstances.length; i++) {
        var plugin = table._pluginInstances[i];
        if (plugin instanceof MelUi.Table.plugins.Export) {
            plugin.export();
            break;
        }
    }
}

3.5 事件总线 events

events 是 options 里的事件回调集合。所有交互都通过内部 eventBus 派发，业务既可以在初始化时用 events 配置，也可以用实例 on() 动态监听。

事件说明（事件总线 eventBus）

两条硬规则先记住：

  1. 事件名不带 on。总线上的名字是 cellClick、rowClick；只有 events 配置里才写成 onCellClick。
  2. 先注册，再触发。用 table.on() 时监听要写在操作之前（见 监听方式 的时序提醒）。

回调参数名词约定：

参数名含义
rowId行唯一标识（字符串，如 'r1'）。不是索引，也不是行对象。行没被删除前在当前实例内一直不变，翻页、排序都不影响；可与 getRowById(rowId) 配合取回原始行。它是运行期临时标识，不要存到后端。
rowIndex行索引（数字），与当前数据源顺序对应；翻页、排序后会变，不要拿它做长期标记。负数索引表示当前页新增的草稿行。
rowData本行业务数据副本：只含业务字段，已剥离 _rowIndex / _rowId / _status 等内部字段。改它不影响数据源，要改数据请用 setCellValue。
selectedRows选中行数组，每项同样是纯业务字段副本。
expanded展开行状态：true 展开 / false 收起。

事件列表

事件名events 里的函数名回调参数触发时机
renderedonRendered{rows, total, pageNo, pageSize}完成一次整体渲染后触发。
rows = 本次渲染的当前页行数组（每项纯业务字段副本，不含 _rowId）；total = 列表总记录数（按 remotePaging + enableRemotePagingFallback 规则计算）；pageNo = 当前页码；pageSize = 每页条数。
rowAddonRowAdd{rowId, rowData, rowIndex}新增行完成后触发。
rowDeleteonRowDelete / onDeleteRow{rowId, rowData, rowIndex}删除行完成后触发。onDeleteRow 是同一事件的另一个配置名。
rowClickonRowClick{rowId, rowData, rowIndex}点击行内任意单元格时触发。点 RowExpand 的箭头列不会触发。
cellClickonCellClick{rowId, rowData, cell:{rowIndex, field, element}}点击单元格时触发（任何列都会触发）。cell.field 可判断点了哪一列。
cellChangeonCellChange{rowId, rowData, rowIndex, field, newValue, oldValue}单元格值变化时触发：用户输入、代码 setCellValue / setRowData 均会触发。
selectChangeonSelectChange单行勾选：{rowId, rowData, checked, selectedRows}
批量操作：{selectedRows}		选中状态变化时触发（需 Checkbox 插件）。
点某行勾选框时带 rowId / rowData / checked；
selectAll / selectNone / invertSelect / setSelectedKeys / clearSelection / 表头全选只给 selectedRows。
sortChangeonSort{field, order}排序完成时触发（需 Sort 插件）。order 为 'asc' / 'desc'。
pageChangeonPageChange{curpage, pagesize}翻页或切换每页条数时触发（需 Pagination 插件）。
expandChangeonExpandChange{rowId, rowData, expanded}行展开 / 收起状态切换完成后触发（需 RowExpand 插件）。
groupHeaderClickonGroupHeaderClick{column, element, event}合并表头时点击分组表头（父级 th）触发（需 HeaderMerge）。分组列不参与排序。
单行事件统一口径： rowClick / cellClick / cellChange / rowAdd / rowDelete / expandChange / selectChange（单行触发） 都把 rowId 作为独立顶层参数给出，并且 rowData 只含业务字段。 全局 / 批量 / 表头类事件（rendered / sortChange / pageChange / groupHeaderClick）没有「某一行」的概念，因此不带 rowId。
内部事件：总线里还有 renderBody、summaryRequest、summaryChange、headerClick 等供内部模块 / 插件协作使用，业务不要监听、也不要依赖其参数。

监听方式

方式一：初始化时通过 events 配置（事件名前加 on）。表格创建过程中触发的事件（如 rendered）只能用这种方式接。

var table = MelUi.Table({
    el: '#table-box',
    columns: columns,
    data: data,
    plugins: ['Pagination'],
    events: {
        onPageChange: function(data) {
            console.log('页码：', data.curpage, '每页条数：', data.pagesize);
        },
        onRendered: function(data) {
            console.log('渲染完成，当前页行数：', data.rows.length);
        }
    }
});

方式二：实例 on() 动态监听（事件名不加 on）。

table.on('pageChange', function(data) {
    console.log('页码：', data.curpage, '每页条数：', data.pagesize);
});
⚠️ 时序提醒：用 table.on() 时，监听要先注册好，再执行操作。
❌ 错误：把 table.on('rowAdd', fn) 写在按钮点击函数里、addRow() 之后 —— 事件已经抛完才注册，本次收不到回调，还会重复注册多份监听。 
// 错误示例
function btnAddClick() {
    table.addRow({name: '测试'}, 'first');
    table.on('rowAdd', function(e) {   // 事件已触发完毕，这里收不到本次新增
        console.log(e);
    });
}

// 正确示例：on 写在点击函数外面，只注册一次
var table = MelUi.Table({ /* ... */ });
table.on('rowAdd', function(e) {
    console.log('新增行', e);
});
function btnAddClick() {
    table.addRow({name: '测试'}, 'first');
}

常用组合示例

// 1. 单元格改动后做联动（改了面积自动算总价）
table.on('cellChange', function(data) {
    if (data.field === 'mj') {
        var price = table.getRowData(data.rowIndex).scjj;
        table.setCellValue(data.rowIndex, 'zje', (parseFloat(data.newValue) * parseFloat(price)).toFixed(2));
    }
});

// 2. 已选行数展示
table.on('selectChange', function(data) {
    document.getElementById('selected-count').innerHTML = '已选 ' + data.selectedRows.length + ' 行';
});

// 3. 点单元格拿到对应原始行（rowId → getRowById）
table.on('cellClick', function(data) {
    var rawRow = table.getRowById(data.rowId);   // 内部原始行对象（含内部字段）
    console.log('点了', data.cell.field, rawRow);
});

// 4. 展开行懒加载详情
table.on('expandChange', function(data) {
    if (!data.expanded) return;
    requestDetail(data.rowData.id, function(res) {
        document.getElementById('detail-' + data.rowId).innerHTML = res.html;
    });
});

// 5. 后端远程分页请求后端
table.on('pageChange', function(data) {
    if (table.options.remotePaging == false) return; // 仅开启后端远程分页(remotePaging = true)才请求后端数据
    if (table.isFallbackPaging) return; // 兜底降级中：内部已对当前数据做本地分页，切勿再请求后端覆盖数据
    // 请求后端
    requestList(data.curpage, data.pagesize, function(res) {
        table.setData(res.list);
    });
});

4. 实例 API

表格实例上挂的全部方法与只读属性。行索引 rowIndex 从 0 开始，翻页、排序后会变；实例销毁后所有调用都会被忽略。

4.1 实例只读属性

属性类型说明
table.isDestroyedBoolean是否已销毁。true = 已销毁，此时所有实例 API 调用都被忽略（可能打印告警）；false = 正常可用。
table.isFallbackPagingBoolean当前是否处于「降级兜底分页」状态。true 表示后端 total 不可信、组件在用当前数据做前端本地分页；onPageChange 里据此判断，true 时不要再请求后端。每次 setData / setRows 后自动重算。
table.optionsObject合并默认值后的最终配置对象，只读用途（如判断 table.options.remotePaging）。不要改它来改表格行为。

4.2 实例方法

事件绑定

方法参数说明
on(eventName, handler)事件名, 回调监听事件，事件名不带 on（详见 3.5 事件总线）。
off(eventName, handler)事件名, 回调解绑事件，需传入同一个函数引用。

销毁实例

方法参数说明
destroy()—销毁实例：清理 window.resize 监听、表身 scroll 监听、恢复 body 样式、销毁全部插件（含插件插入的虚拟列与渲染钩子）、清空数据源与容器 DOM。重复调用不会报错。
destroy() 调用时机：① SPA 路由切换、页面跳转前；② 弹窗 / 抽屉关闭时；③ 同一容器要重新 new 一个表格实例前；④ 组件卸载生命周期内。 整页刷新无需手动调用。调用 destroy 后不要再继续使用该实例的 addRow / setData / render 等 API。

数据读取

方法返回说明
getData()Array获取整表数据（数据源行数组）。
getRowData(rowIndex)Object / null按行索引获取行数据对象。
getRowById(rowId)Object / null按 rowId 获取行数据，找不到返回 null。
返回内部原始行对象（含内部字段），可直接改值但不会触发重绘 —— 要重绘请用 setCellValue。
rowId 来自单行事件参数（rowClick / cellClick / cellChange / selectChange / rowAdd / rowDelete / expandChange）。
getSelectedData()Array获取选中行的数据数组（需 Checkbox 插件）。
getDirtyData()Array获取有变动的行：新增 + 修改。常用于保存前只提交变更数据。
注意区分：getData() / getRowData() / getSelectedData() / getDirtyData() 返回的是内部行对象（含 _rowIndex / _rowId / _status 等内部字段）； 事件回调里的 rowData、rendered.rows 是纯业务字段副本。两者不要混用。

数据写入

方法参数说明
setCellValue(rowIndex, field, value)行索引, 字段, 新值设置某行某列的值并局部重绘该单元格；会触发 cellChange 事件。
setRowData(rowIndex, data)行索引, {字段: 值}批量设置某行多个字段并重绘该行。
addRow(data, position)行数据(可选), 'first' / 'last'新增一行。插入位置由 addRowMode 决定：currentPage 插当前页，global 插全局数组；position 控制首 / 尾，默认 'last'。
新增后自动滚动定位并聚焦行内第一个 text / password / textarea 输入框（跳过 checkbox / radio / button / hidden）。
本方法目前无返回值，要拿新行请用 rowAdd 事件或 getData()。
deleteRow(rowIndex)行索引删除指定行，重绘表身，抛 rowDelete 事件。
clearData()—清空全部数据。
setData(data)行数据数组整表替换数据并全量重绘；后端远程分页时用于回填后端返回的当页数据。

状态操作

方法参数说明
markSaved(rowIndex)行索引 或 'all'标记行状态为已保存，'all' 表示全部行（配合 StateColumn）。
setCellReadonly(rowIndex, field, readonly)行索引, 字段, Boolean动态设置某格只读 / 可写。作用于当前 DOM 中的输入控件，行重绘后需重新设置。

多选行-选中操作（需启用Checkbox 插件）

方法参数说明
selectAll()—全选。单选模式静默忽略。
selectNone()—全不选。单选模式静默忽略。
invertSelect()—反选。单选模式静默忽略。
setSelectedKeys(rowIndexes)行索引数组按行索引设置选中行。单选模式只取第一条；传空数组等于清空选中。
clearSelection()—清空全部选中。

数据校验

方法返回说明
validate(rowIndex|'all')Number|String校验必填与列级钩子：列上配置了 required:true 或 validator 才会被检查。返回值为错误提示文本，空字符串表示通过。每行每列一条提示，换行分隔。必填提示格式 第N行【列标题】不能为空；validator 提示格式 第N行【列标题】+ 你返回的文本。必填为空时跳过 validator，不会重复提示。
rowIndex 可传的值：
行号索引值(从0开始)： 表示校验指定行
字符串'all'：表示校验全部行。
validateUnique()String校验唯一值（columns 需先设 unique:true）。返回重复值提示文本，空字符串表示通过。
// 保存前校验
var err1 = table.validate('all');
var err2 = table.validateUnique();
if (err1 || err2) {
    alert(err1 + err2);
    return;
}
commit(table.getDirtyData());   // 校验通过后只提交变更数据

渲染控制

方法参数说明
render()—全量重绘表格（含表头、表身）。
renderRow(rowIndex)行索引只重绘指定行。
renderCell(rowIndex, field)行索引, 字段只重绘指定单元格。
setColumnVisible(field, visible, skipRender)字段, Boolean, Boolean(可选)运行时切换列显隐（改列配置的 visible 并重绘）。只是不显示，列与数据都还在，可随时切回来。
不传 skipRender 或传 false：立即重绘；
传 true：先只改配置不重绘，批量切多列时最后统一 render() 一次，避免连续重绘。
隐藏列不占宽度，fixedLeftColumns 的冻结列数量按「可见列」计算，隐藏列会被跳过。
列显隐的两种写法： 
// ① 单列切换：立即生效（内部会调 render()）
table.setColumnVisible('dist', false);   // 隐藏省市区
table.setColumnVisible('dist', true);    // 再显示回来

// ② 批量切换：先跳过重绘，最后统一渲染一次
table.setColumnVisible('dist', false, true);
table.setColumnVisible('remark', false, true);
table.render();
注意：skipRender:true 时表格不会马上变化，必须补一次 render()； 不传该参数等价于 skipRender:false，函数内部会直接调 table.render()。

5. 注意事项

这一节全是「不按这个做就会出问题」的条目，建议上线前逐条过一遍。
  1. 数据以数据层为准。读业务数据用 getData() / getRowData() / getDirtyData()，不要遍历 DOM 读 input 的 value。
  2. 不要直接改内部对象。直接改 table.dataStore.rows 不会触发重绘；请用 setCellValue / setRowData / setData。
  3. 事件里的 rowData 只读。它是纯业务字段副本，改它不影响数据源；要改数据用 setCellValue。要按 rowId 拿原始行用 getRowById()。
  4. rowId 不要入库。它是前端运行期临时标识（如 'r1'），翻页排序不变、删行失效；长期标记请用业务主键。
  5. 列宽是固定 px。基于 table-layout:fixed，不按内容自适应；要铺满容器用 fitWidth:true 按 width 权重拉伸。
  6. fitViewport 会改 body 样式。开启后设置 body overflow-y:hidden，destroy() 时自动恢复；同一页面不要多个表格同时开启。
  7. remotePaging=true 时 addRowMode 无效。后端远程分页下统一按全局数据处理。
  8. 兜底降级判断。remotePaging=true 且 enableRemotePagingFallback=true 时，后端 total 不可信会自动降级为前端本地分页；此时 pageChange 里务必用 table.isFallbackPaging 判断，为 true 时不要再请求后端。
  9. 新增行聚焦。自动聚焦行内第一个 text / password / textarea，checkbox / radio / button / hidden 会跳过；没有可输入控件时静默不聚焦。内部有 30ms 延时兜底，极端卡顿环境可能偶发失效。
  10. 插件列会影响列顺序与冻结。SerialNo / Checkbox 插最前，StateColumn 默认插最后，RowExpand 箭头列固定最左；用 fixedLeftColumns 冻结时要把这些列算进数量。
  11. 合并表头层级别太深。层级由 children 决定，支持任意层，建议最多三级；层数多时列宽会很挤，冻结列与滚动同步请自己回归一遍。
  12. 展开行不是树形表格。RowExpand 只在行下方插入一条跨列详情行，内容来自 expandRender；它不产生子数据行、不能嵌套展开，也不参与编辑 / 勾选 / 排序。
  13. IE9 环境。组件内部已规避 let / const / 箭头函数 / 模板字符串 / classList / dataset；业务代码同样不要用 ES6+。展开箭头用 CSS 画（IE9 走 -ms-transform），不依赖字体图标。
  14. 页面卸载必须 destroy。SPA 路由切换、弹窗关闭、容器复用前调用 table.destroy()，避免 resize / scroll 监听泄漏。
  15. 自定义渲染器注意 XSS。返回的 HTML 直接写进单元格或展开区域，用户输入内容请先转义。
