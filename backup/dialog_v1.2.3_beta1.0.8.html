MelUi Dialog 弹窗对话框组件

版本：v1.2.3 beta 1.0.8 | 兼容IE9~11、移动端自适应 | MelUi.xxx / melui.xxx 大小写均可调用

一、标准引入方式


<link rel="stylesheet" href="../src/components/dialog/index.css">
<script src="../src/components/dialog/index.js"></script>

二、默认配置参数


var defaults = {
    title: "", // 弹窗标题(可选)。空字符串不渲染标题栏。
    theme: "info", // 按钮主题(可选)。值：info/success/warning/danger/default。
    type: "", // 内容警示图标类型(可选)。值：success/warning/error/info。空不显示图标。
    showClose: true, // 是否显示右上角关闭叉号(可选)。值：true是,false否。
    mask: true, // 是否显示遮罩层(可选)。值：true是,false否。
    maskClosable: true, // 点击遮罩是否关闭弹窗(可选)。值：true是,false否。
    btnDirection: "horizontal", // 按钮排布方向(可选)。值：horizontal横向,vert竖向。
    btnFullWidth: false, // 按钮是否通栏铺满整行(可选)。值：true是,false否。横向时按钮在一行内等分，竖向时才垂直排列。
    btnDisabled: false, // 是否一键禁用全部底部按钮(可选)。值：true是,false否。
    buttons: null, // 自定义按钮数组，优先级最高(可选)。数组项格式：{ text: "按钮文字", type: "按钮类型" }，type值：info/success/warning/danger/default/primary；也支持字符串快捷写法：["取消","确定"]，最后一项自动用弹窗主题色。
    message: "", // 普通文本内容(可选)。dangerouslyUseHTMLString=true时该字段无效。
    content: "", // HTML内容(可选)。仅dangerouslyUseHTMLString=true生效。
    dangerouslyUseHTMLString: false, // 是否开启HTML解析(可选)。值：true是,false否。开启后使用content字段。
    center: false, // 是否整体居中布局(可选)。值：true是,false否。true时header、body、footer全部内容水平居中。
    textCenter: false, // 是否仅正文文本居中(可选)。值：true是,false否。优先级高于center。
    fullScreen: false, // 是否全屏弹窗(可选)。值：true是,false否。
    width: "auto", // 弹窗宽度(可选)。auto使用组件默认，支持数字、px、百分比。
    height: "auto", // 弹窗整体高度(可选)。auto使用组件默认，支持数字、px、百分比。
    footerStickyBottom: true, // 设置height或fullScreen时，按钮是否固定在弹窗底部(可选)。值：true是,false否。
    contentMaxHeight: "", // 内容区域最大高度(可选)。height生效时本参数失效。
    fontSize: "", // 内容区文字大小(可选)。空则使用默认16px，支持数字、px。
    device: "", // 一键移动端模式(可选)。值："phone"开启，空不开启；不自动UA检测。
    prompt: { // prompt输入框专属配置(可选)。仅调用prompt()时生效
        inputType: "input", // 输入框类型(可选)。值：input单行,textarea多行。
        placeholder: "", // 输入框占位提示文字(可选)。
        defaultValue: "", // 输入框默认值(可选)。
        unit: "" // 输入框右侧单位文字，例：元、㎡(可选)。
    },
    onClick: null, // 按钮点击回调(可选)。ret为按钮序号从1开始；prompt会附带输入框value。
    onOpen: null, // 弹窗打开完成回调(可选)。DOM已挂载完成，入参为当前实例。
    onClose: null // 弹窗关闭回调(可选)。所有关闭方式均触发；return false可阻止关闭，入参为当前实例。
};

Tip：MelUi.Tip；Toast：MelUi.Toast；onClose返回false可拦截弹窗关闭；弹窗打开会自动锁定页面滚动，全部关闭后恢复。

dialog 与 alert：dialog 是通用弹窗入口，alert 等价于不传 buttons 的 dialog（默认一个"确定"按钮），二者底层都是 new MelUi.Dialog()，参数完全一致；confirm 默认"取消+确定"两个按钮，prompt 默认一个"确定"按钮。

buttons 字符串快捷写法：buttons: ["取消", "确定"] 等价于 [{ text: "取消", type: "default" }, { text: "确定", type: "弹窗主题色" }]，最后一项自动用 theme 颜色；只想全灰时用对象写法显式指定 type: "default"。

三、调用示例

1、弹窗快捷调用 dialog / alert
dialog 极简调用
只传 message，其余全部使用默认参数

melui.dialog({
    message: "保存配置完成"
});
alert 极简调用
只传 message，自动带一个"确定"按钮

melui.alert({
    message: "操作已执行完毕"
});
alert 无标题
无标题时 message 对齐弹窗整体垂直中心

melui.alert({
    message: "没有标题的弹窗"
});
alert 有标题
有标题的情况，标题、内容默认居左显示 

melui.alert({
    title: "提示",
    message: "有标题的弹窗"
});
alert 不同主题
theme: success，取消按钮也跟随绿色调

melui.alert({
    title: "成功提示",
    message: "文件上传全部完成",
    theme: "success"
});
alert 自定义按钮 - 字符串快捷写法
传入 buttons 不会被默认按钮覆盖

melui.alert({
    title: "测试alert自定义按钮",
    message: "alert现在支持自定义buttons， 直接传入按钮显示文字即可",
    buttons: ['取消1', '取消2', '确定']
});
alert 自定义按钮 - 数组项格式
传入 buttons 不会被默认按钮覆盖

melui.alert({
    title: "测试alert自定义按钮",
    message: "alert现在支持自定义buttons，传入按钮文本和样式 ",
    buttons: [
        { text: "我不知道,别烦我", type: "warning" },
        { text: "好的我知道了", type: "success" }
    ]
});
type 警示图标
type: "warning"，图标显示在内容（message）前，type 与 theme 独立控制

melui.alert({
    title: "操作警告",
    message: "检测到风险操作，请确认后继续执行",
    type: "warning",
    theme: "warning"
});
title 为空，验证关闭按钮
标题为空时关闭按钮依然显示，message 对齐弹窗整体垂直中心

melui.dialog({
    title: "",
    showClose: true,
    message: "没有标题，右上角关闭按钮应当显示，内容垂直居中",
    buttons: [
        { text: "关闭", type: "info" }
    ]
});
width 传入纯数字
width: 500 自动补 px

melui.dialog({
    title: "数字宽度测试",
    width: 500,
    message: "width直接写数字500，自动补px"
});
fontSize 内容字号
控制中间内容文字大小，默认16px，此处改为20px

melui.dialog({
    title: "内容字号测试",
    message: "这段文字的字号是20px",
    fontSize: 20
});
2、Tip消息提示
调用方式说明

//（1）快速调用：直接传入字符串
// 成功 MelUi.Tip.success("消息")
// 警告 MelUi.Tip.warn("消息")
// 信息 MelUi.Tip.info("消息")
// 错误 MelUi.Tip.error("消息")
// 平实 MelUi.Tip.plain("消息")

//（2）完全调用：传入object参数
MelUi.Tip({
    type: "error", // success成功 / warn警告 / info信息 / error错误 / plain平实
    message: "请求异常，请稍后重试", // 提示文本内容
    duration: 5000, // 自动关闭延时(毫秒)，0常驻
    position: "bottom" // 弹出位置 top / bottom
});
Tip-success 成功
绿色系：背景 #f0f9eb，边框 #e1f3d8，文字 #67c23a

MelUi.Tip.success("操作执行成功");
Tip-warn 警告
黄色系：背景 #fdf6ec，边框 #faecd8，文字 #e6a23c

MelUi.Tip.warn("请注意填写必填项");
Tip-error 错误
红色系：背景 #fef0f0，边框 #fde2e2，文字 #f56c6c

MelUi.Tip.error("接口调用失败");
Tip-info 信息
灰色系，图标 ⓘ

MelUi.Tip.info("系统将于今晚维护");
Tip-plain 平实（天猫风格）
白底黑字，无图标无主题色

MelUi.Tip.plain("普通平实提示文案");
Tip 完整对象配置
type + message + duration + position 组合使用

MelUi.Tip({
    type: "error",
    message: "请求异常，请稍后重试",
    duration: 5000,
    position: "bottom"
});
Tip 多条堆叠
多条同时出现自动垂直堆叠，不重叠

MelUi.Tip.info("第一条消息");
MelUi.Tip.success("第二条消息");
MelUi.Tip.warn("第三条消息");
Tip 开启 mask 遮罩
duration 设为0常驻，点击右上角×关闭

MelUi.Tip({
    type: "info",
    message: "带遮罩的Tip，点击右上角×关闭",
    mask: true,
    duration: 0
});

5、prompt输入弹窗
prompt 单行输入 + 单位
默认只有一个"确定"按钮；unit 显示在输入框右侧

melui.prompt({
    title: "输入金额",
    prompt: {
        inputType: "input",
        placeholder: "请输入金额",
        defaultValue: "100",
        unit: "元"
    },
    onClick: function(ret, val) {
        if(ret === 1) {
            melui.alert({ message: "输入：" + val });
        }
    }
});
prompt 自定义双按钮
传入 buttons 自定义"取消+保存"，ret 从1开始

melui.prompt({
    title: "请输入昵称",
    prompt: {
        inputType: "input",
        placeholder: "请输入昵称"
    },
    buttons: [
        { text: "取消", type: "default" },
        { text: "保存", type: "success" }
    ],
    onClick: function(ret, val) {
        if(ret === 2) {
            melui.alert({ message: "昵称：" + val });
        }
    }
});
prompt textarea 多行 + 固定高度
height: 300，输入框自动占满中间内容高度，按钮固定在底部

melui.prompt({
    title: "备注信息",
    height: 300,
    prompt: {
        inputType: "textarea",
        placeholder: "请输入备注内容"
    }
});
